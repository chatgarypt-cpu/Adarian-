## 4. 详细技术方案

### 4.1 领域包生命周期

```
安装: 将包目录放入 packages/ → 重启 core 自动发现
加载: core 启动 → scan_packages() → 校验 package.yaml
     → 合并 skills → 注册 planner skills → 初始化数据路径
卸载: 删除包目录 → 重启 core → 自动清理
热重载: POST /api/admin/domains/reload → 重新扫描 packages/
```

### 4.2 Skill 合并策略

```python
# genflow-common/domain_loader.py

@dataclass
class DomainPackage:
    name: str
    version: str
    display_name: str
    skills: list[SkillDefinition]      # 来自 skills.yaml
    planner_module: str | None
    planner_skills: list[str]
    models: list[str]
    data_root: Path

def scan_packages(packages_dir: Path) -> dict[str, DomainPackage]:
    """扫描 packages/ 下所有领域包，返回 {domain_id: DomainPackage}"""
    packages = {}
    for pkg_dir in packages_dir.iterdir():
        if not pkg_dir.is_dir() or pkg_dir.name.startswith("_"):
            continue
        pkg_yaml = pkg_dir / "package.yaml"
        if not pkg_yaml.exists():
            continue
        pkg = parse_package_yaml(pkg_yaml)
        packages[pkg.name] = pkg
    return packages

def merge_skills(
    core_skills: SkillRegistry,
    domain_packages: dict[str, DomainPackage],
) -> SkillRegistry:
    """合并 core skills 与所有领域包 skills，校验无 ID 冲突"""
    merged = SkillRegistry()
    merged.add_all(core_skills)
    for domain_id, pkg in domain_packages.items():
        for skill in pkg.skills:
            skill.domain = domain_id
            merged.add(skill)
    return merged
```

### 4.3 Planner Skill 动态加载

```python
# genflow-core/chat/planning/domain_loader.py

import importlib
import sys
from pathlib import Path

def load_planner_skills(packages: dict[str, DomainPackage]) -> dict[str, callable]:
    """动态加载所有领域包的 Planner Skills"""
    skills = {}
    for domain_id, pkg in packages.items():
        if not pkg.planner_module:
            continue
        pkg_dir = Path("packages") / domain_id
        if str(pkg_dir) not in sys.path:
            sys.path.insert(0, str(pkg_dir))
        mod = importlib.import_module(pkg.planner_module)
        for skill_name in pkg.planner_skills:
            fn = getattr(mod, skill_name, None)
            if fn and callable(fn):
                skills[f"{domain_id}.{skill_name}"] = fn
    return skills
```

Planner 调用端改造（`progressive_selection.py`）:
```
  现在: from .planner_skills import ... (静态 import)
  目标: domain_loader.get_planner_skill(skill_name) → 动态 dispatch
```

### 4.4 Agent 容器内领域模型加载

```python
# genflow-agent-runtime/domain/__init__.py

import importlib
import sys
from pathlib import Path

_DOMAIN_MODELS_CACHE: dict[str, object] = {}

def load_domain_model(domain_id: str, model_name: str):
    """动态加载领域模型（容器内 /packages/<domain>/models/）"""
    cache_key = f"{domain_id}.{model_name}"
    if cache_key in _DOMAIN_MODELS_CACHE:
        return _DOMAIN_MODELS_CACHE[cache_key]

    model_path = Path(f"/packages/{domain_id}/models")
    if str(model_path) not in sys.path:
        sys.path.insert(0, str(model_path))
    mod = importlib.import_module(model_name)
    _DOMAIN_MODELS_CACHE[cache_key] = mod
    return mod
```

Agent 主入口改造:
```
  现在: election_agent.py 直接调用 TaiwanElectionAnalyzer 等
  目标: run_node.py → system_prompt.py → 根据 node skill domain
        → 动态 import domain_models
        → 如果节点需要选举模型 → import election_tw.models
        → 如果节点是通用技能 → 只用 runtime_builtin_tools
```

### 4.5 Docker 构建改造

```yaml
# docker/docker-compose.yml (关键变更)

services:
  genflow-core:
    image: genflow-core:latest
    container_name: genflow-core
    build:
      context: ..
      dockerfile: docker/Dockerfile.core
    volumes:
      - ../packages:/packages:ro       # 🆕 领域包挂载
      - workspace:/workspace

  genflow-agent:
    image: genflow-agent:latest
    build:
      context: ..
      dockerfile: docker/Dockerfile.agent

  # Agent 节点通过 docker-py 创建容器时注入 volume mount:
  #   /packages/<domain> → /packages/<domain>:ro
```
