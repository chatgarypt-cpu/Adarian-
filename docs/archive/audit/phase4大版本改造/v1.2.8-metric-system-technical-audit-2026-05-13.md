## 3. Executive Summary

1. **x(t) 是什么**: x(t) 是所有 Agent（含 event entities）当前立场分数（1-10）的算术均值，由 `calculate_global_metrics()` 在每轮 tick 后确定性计算。代码内部名为 `mean_stance`，对外以 `x(t)` 符号表示。

2. **极化指数是什么**: `polarization_index = std_stance / mean_stance`，即变异系数（Coefficient of Variation），不是学术界正式的极化测量（如 Esteban-Ray 指数）。schema 中标注为 `ge=0.0, le=1.0`，但数学上存在超出 1.0 的理论可能。

3. **拐点是什么**: 由 `identify_inflection_points()` 确定性计算：当相邻两轮 polarization_index 变化绝对值 > 0.1 时触发。阈值 0.1 硬编码在 `report_agent.py:711`，不在 config.py 中。最多返回 3 个拐点。拐点是模拟系统内部的状态变化标记，不代表现实舆情拐点。

4. **当前代码是否确定性计算**: x(t)、极化指数、stance_delta、风险等级均为确定性代码计算。拐点检测也是确定性代码计算（非 LLM）。唯一 LLM 参与的是个体 stance 的提议值（但会经过代码侧 `apply_stance_constraint()` 约束后才生效）。

5. **是否有论文直接依据**: **无**。仓库中没有任何 PDF 论文文件，源码和 prompt 中均无学术引用。所有指标均为工程代理指标（Engineering Proxy Metrics），非基于已发表论文的正式测量。

6. **当前指标是否合理**: **有条件通过**。作为 MVP 的内部情景比较和趋势判断工具基本合理，但存在若干严重问题需修复：`assess_risk()` 方向盲（只判高 x(t) 为风险），event entities 固定 stance=5.0 拉偏 x(t)，silent agent drift 始终为正导致系统性向上偏差。

7. **主要限制**: x(t) 不等同于现实舆情情绪；极化指数用 CV 而非真正的双峰极化测量；拐点阈值 0.1 未标定且产生高假阴性；单次运行无置信区间；收敛检测已被禁用；无群体层面的代码侧聚合指标；无对应单元测试。

## 5. x(t) Explanation

### 5.1 定义

x(t) 是第 t 轮模拟中所有 Agent（含 event entities 和 opinion spreaders）当前立场分数的**算术平均值**。

```python
# src/phase3/tick_simulation.py:765
mean_stance = statistics.mean(stances)
```

其中 `stances` 包含 `self.agent_stances.values()` 中的所有值，即 event entities 和 opinion spreaders 的立场分数。

**源码证据**：
- 计算位置：`src/phase3/tick_simulation.py:756-774`，函数 `calculate_global_metrics()`
- Schema 定义：`src/schemas/phase3.py:62-67`，`GlobalMetrics.mean_stance`，描述为 `"全局平均立场分，即 x(t)"`
- 调用位置：每轮 tick 结束后在 `run_tick()` (line 862) 和 `run_tick_0()` (lines 891-896) 中调用

### 5.2 生成过程

1. **初始值**（Tick 0 前）：event entities 固定为 5.0；opinion spreaders 从 Phase 1 的 I/P 映射：若 P=+1 则 stance=I，若 P=-1 则 stance=11-I，然后施加 jitter (Core ±5%, Periphery ±15%)
2. **每轮更新**：发言者由 LLM 提议新 stance → 经 `apply_stance_constraint()` 约束 → 写入 `self.agent_stances`；沉默者由 `update_silent_agent()` 计算 drift → 更新 stance
3. **指标计算**：`calculate_global_metrics()` 从 `self.agent_stances` 取所有值 → 计算 mean/std/polarization_index
4. **序列化**：作为 `TickLog.global_metrics` 写入 `tick_logs.json`

### 5.3 取值范围

- 个体 stance：**1.0 – 10.0**（由 `phase3.py` schema 中 `AgentEntry.current_stance` 的 `ge=1.0, le=10.0` 约束）
- x(t)：**1.0 – 10.0**（群体均值，范围同个体）
- 业务含义：
  - 1.0–3.0：模拟批评倾向
  - 4.0–6.0：模拟中立观望
  - 7.0–10.0：模拟支持倾向

### 5.4 业务含义与限制

- x(t) 高 → 群体模拟立场偏支持；x(t) 低 → 群体模拟立场偏批评
- **x(t) 不是现实舆情情绪**，是模拟系统中 Agent 立场的统计聚合
- x(t) 包含了固定 stance=5.0 的 event entities，会系统性拉向中性（在 test8 中约 +15% 偏差）
- 当前报告中将 x(t) 称为"情绪均值"不够准确

### 5.5 报告中建议名称

| 当前使用 | 建议使用 | 理由 |
|----------|----------|------|
| x(t)（数学符号直出）| 模拟立场均值 | 数学符号应在正文中后台化 |
| 情绪均值 | 模拟立场均值 | "情绪"不准确 — 系统模拟的是立场(stance)非情绪(emotion) |
| x(t)均值 | 本轮模拟群体立场均值 | 增加"模拟"限定 |

## 6. Polarization Index Explanation

### 6.1 定义

极化指数是立场标准差与立场均值的比值，即**变异系数（Coefficient of Variation）**。

### 6.2 公式

```python
# src/phase3/tick_simulation.py:766-768
std_stance = statistics.stdev(stances) if len(stances) > 1 else 0.0
polarization_index = std_stance / mean_stance if mean_stance > 0 else 0.0
```

### 6.3 源码证据

- 计算位置：`src/phase3/tick_simulation.py:768`
- Schema 定义：`src/schemas/phase3.py:66` — `Field(ge=0.0, le=1.0, description="极化指数 = std/mean")`
- 存储位置：`TickLog.global_metrics.polarization_index` → `tick_logs.json`
- 消费位置：拐点检测（threshold=0.1）、风险评估（threshold=0.5）、风险类型选择、轨迹描述、演化阶段判定

### 6.4 业务含义

- 0.0–0.3：低分化（意见相对一致）
- 0.3–0.7：中等分化（意见开始分散）
- 0.7–1.0：高冲突/高分化（意见严重分裂）
- 上升 → 群体立场差异扩大；下降 → 立场趋于收敛

### 6.5 重要限制

1. **CV 不是真正的极化测量**：真正的极化（如 Esteban-Ray 指数）测量的是双峰聚类，CV 测量的是相对离散度。一个均匀分布的意见群和一个两极分化的意见群可能具有相同的 CV。
2. **Schema 约束 `le=1.0` 可能被违反**：若 9 个 agent 在 stance=1.0，1 个在 stance=10.0，CV ≈ 1.50 > 1.0。当前因 event entities 锚定在 5.0 不太可能触发，但没有代码层面的保护。
3. **`statistics.stdev()` 使用样本标准差 (N-1)**：对于小 N（最多 15 agent），N vs N-1 的差异可观。
4. **无归一化对标基线**：不同模拟之间的极化指数不可直接横向比较。

### 6.6 报告中建议名称

| 当前使用 | 建议使用 | 理由 |
|----------|----------|------|
| 极化指数 | 模拟极化指数 | 增加"模拟"限定，与真实社会极化测量区分 |
| polarization_index（英文泄露）| 群体分化水平 | 已在 `_replace_raw_metric_field_names` 中处理 |

**模型侧**：
- 拐点表示模拟系统中 polarization_index 发生单轮显著跳变（Δ > 0.1）
- 可能来自整体极化变化，而非关键群体立场跳变

**产品侧**：
- 拐点是"需要关注的模拟演化节点"，标识值得解释的轮次
- **不等于现实舆情传播中的真实拐点**
- 只能说明模拟条件下出现了显著状态变化

**治理侧**：
- 拐点作为报告中的"观察信号"，提示哪个群体、哪一轮值得解释

## 8. Mathematical Formalization

### 8.1 Individual Stance

```latex
x_i(t) \in [1.0,\;10.0], \quad i \in \{1,\dots,N\},\; t \in \{0,\dots,T\}
```

Initial value for opinion spreaders (Phase 1 → Phase 2):
```latex
x_i(0) = \begin{cases}
I_i & \text{if } P_i = +1 \\
11 - I_i & \text{if } P_i = -1
\end{cases}
```

where $I_i \in [1.0, 10.0]$ is stance intensity, $P_i \in \{+1, -1\}$ is stance direction.

Event entities: $x_i(t) = 5.0$ for all $t$ (fixed).

### 8.2 Group Mean Stance x(t) — CURRENT IMPLEMENTATION

```latex
\bar{x}(t) = \frac{1}{N}\sum_{i=1}^{N} x_i(t)
```

Computed with Python `statistics.mean()`.

**Note**: $N$ includes ALL agents (event entities + opinion spreaders). Event entities are fixed at 5.0 for all $t$.

Source: `src/phase3/tick_simulation.py:765`

### 8.3 Standard Deviation — CURRENT IMPLEMENTATION

```latex
\sigma_{\text{sample}}(t) = \sqrt{\frac{1}{N-1}\sum_{i=1}^{N}\left(x_i(t) - \bar{x}(t)\right)^2}
```

Uses **sample standard deviation** (N-1 denominator), not population standard deviation.

If $N = 1$: $\sigma(t) = 0.0$

Source: `src/phase3/tick_simulation.py:766` — `statistics.stdev(stances)`

### 8.4 Polarization Index — CURRENT IMPLEMENTATION

```latex
P(t) = \frac{\sigma_{\text{sample}}(t)}{\bar{x}(t)}, \quad \text{with guard: } P(t) = 0.0 \text{ if } \bar{x}(t) \leq 0
```

This is the **Coefficient of Variation (CV)**, not a formal polarization index.

The schema constraint $P(t) \in [0.0, 1.0]$ is a Pydantic validation assertion, **not** a mathematical guarantee. For stances in $[1.0, 10.0]$, the theoretical maximum CV is approximately 1.50.

Source: `src/phase3/tick_simulation.py:768`, `src/schemas/phase3.py:66`

### 8.5 Stance Delta — CURRENT IMPLEMENTATION

Per-agent:
```latex
\Delta x_i(t) = x_i(t) - x_i(t-1), \quad t \geq 1
```

Global mean delta:
```latex
\Delta \bar{x}(t) = \bar{x}(t) - \bar{x}(t-1), \quad t \geq 1
```

Source: `src/phase3/tick_simulation.py:827`, `src/phase3/state_updater.py:28`

### 8.6 Inflection Point Detection — CURRENT IMPLEMENTATION

```latex
\Delta P(t) = P(t) - P(t-1)
```

```latex
\mathbb{I}_{\text{inflection}}(t) =
\mathbf{1}\left(|\Delta P(t)| > \theta_P\right), \quad \theta_P = 0.1
```

When triggered, the pivotal agent is:
```latex
i^* = \arg\max_i |\Delta x_i(t)|
```

Hard cap: at most 3 inflection points returned.

Source: `src/phase4/report_agent.py:683-726`

### 8.7 Risk Level — CURRENT IMPLEMENTATION

Let $\bar{x}_{\text{final}} = \bar{x}(T)$, $P_{\text{final}} = P(T)$, $\Delta\bar{x}_{\text{trend}} = \bar{x}(T) - \bar{x}(0)$.

```latex
\text{RiskLevel} = \begin{cases}
\text{CRITICAL} & \text{if } \bar{x}_{\text{final}} > 7.5 \;\lor\; (\bar{x}_{\text{final}} > 7.0 \land \Delta\bar{x}_{\text{trend}} > 1.0) \\
\text{HIGH}      & \text{if } \bar{x}_{\text{final}} > 6.5 \;\lor\; (\bar{x}_{\text{final}} > 5.5 \land P_{\text{final}} > 0.5) \\
\text{MEDIUM}     & \text{if } \bar{x}_{\text{final}} > 5.0 \;\lor\; (\bar{x}_{\text{final}} > 4.5 \land \Delta\bar{x}_{\text{trend}} > 0.5) \\
\text{LOW}        & \text{otherwise}
\end{cases}
```

Evaluated top-down; first match wins.

Source: `src/phase4/report_agent.py:729-761`

### 8.8 Stance Constraint Mechanics (Supporting)

For speaking agents:
```latex
\delta_{\text{eff}} = \delta_{\text{base}}(b) \cdot \left(1 + \alpha \cdot (s - 0.5)\right)
```

where:
- $b \in \{\text{"strong"}, \text{"weak"}, \text{"none"}\}$ — confirmation bias level
- $\delta_{\text{base}}(\text{"strong"}) = 0.3$, $\delta_{\text{base}}(\text{"weak"}) = 1.0$, $\delta_{\text{base}}(\text{"none"}) = 2.0$
- $s \in [0.0, 1.0]$ — susceptibility
- $\alpha = 0.5$ — `SUSCEPTIBILITY_MODULATION_FACTOR` (config.py:141)

Opinion pressure bonus (only under `minimal_supporters` strategy):
If $\bar{x}(t-1) < 4.0 \land x_i(t-1) \geq 7.0$, then $\delta_{\text{eff}} = \delta_{\text{eff}} \times 1.2$.

```latex
x_i(t) = \text{clamp}_{[1.0, 10.0]}
\begin{cases}
x_i^{\text{proposed}} & \text{if } |x_i^{\text{proposed}} - x_i(t-1)| \leq \delta_{\text{eff}} \\
x_i(t-1) \pm \delta_{\text{eff}} & \text{otherwise}
\end{cases}
```

For silent agents:
```latex
x_i(t) = \text{clamp}_{[1.0, 10.0]}\left(x_i(t-1) + 0.12 \cdot s_i \cdot \frac{\min(|F_i(t)|, 3)}{3}\right)
```

where $F_i(t)$ is the set of followed agent comments agent $i$ sees at tick $t$.

**Key issue**: The drift term $0.12 \cdot s_i \cdot \text{exposure\_factor}$ is **always positive**, creating systematic upward bias in silent agent stances.

Source: `src/phase3/tick_simulation.py:622-677`, `src/phase3/state_updater.py:10-34`

### 8.10 Recommended Formal Definitions

For future iterations, consider:

**Proper polarization index** (Esteban-Ray style):
```latex
P_{\text{ER}} = K \sum_{i=1}^{N} \sum_{j=1}^{N} \pi_i^{1+\alpha} \pi_j |x_i - x_j|
```

where $\pi_i$ is the population weight of group $i$, $\alpha \in [0, 1.6]$ is the polarization sensitivity parameter.

**Change-point detection** (replacing simple threshold):
```latex
\tau^* = \arg\max_{\tau} \left[ \mathcal{L}(x_{1:\tau}) + \mathcal{L}(x_{\tau+1:T}) - \mathcal{L}(x_{1:T}) \right]
```

### 9.3 Related Theoretical Background (SUGGESTIONS ONLY)

以下为**可对齐的理论方向**，并非当前实现的实际基础：

- **Opinion Dynamics** (DeGroot 1974, Friedkin-Johnsen 1990, Hegselmann-Krause 2002): x(t) 作为群体意见均值是这些模型的标准输出变量。但 Adarian 中 x(t) 由 LLM 生成值的算术平均得到，没有权重矩阵驱动的动力学。
- **Bounded Confidence Models** (Hegselmann-Krause, Deffuant-Weisbuch): 通过置信半径 ε 定义极化。当前 CV 不捕捉聚类或双峰性。
- **Polarization Economics** (Esteban-Ray 1994, Duclos-Esteban-Ray 2004): 正式极化指数需要人口子群、群间距离和群内认同。当前 std/mean 与这些不对齐。
- **Agent-Based Modeling (ABM)**: 基于 tick 的模拟结构与 ABM 相近，但正式 ABM 需要数学定义的 agent 更新规则（非 LLM 驱动）和系统参数扫描。
- **SEIR Epidemiological Model**: 设计文档借用了流行病学标签，但当前代码未实现 SEIR 状态转移。

## 11. Limitations

1. **Event entities 固定 stance=5.0 拉偏 x(t)**：event entities 在所有 tick 中保持 5.0，约占总 agent 数的 30-40%，系统性将 x(t) 拉向中性。在 test8 中，仅 opinion spreaders 的均值为 3.57，含 entities 后升至 4.12（+15% 通胀）。

2. **CV（std/mean）不是极化测量**：CV 测量相对离散度，不能区分"意见多样化"和"意见两极化"。学术界正式极化指数（如 Esteban-Ray）需要群内认同和群间距离。

3. **`assess_risk()` 方向盲**：仅判高 x(t) 为风险。对品牌争议、执法纠纷等公众批评为风险的事件类型，低 x(t) 才是风险信号。test8 中 x(t)=4.12 且两个 agent 触底 1.50 却被判"低风险"。

4. **Silent agent drift 始终为正**：`drift = 0.12 × susceptibility × exposure_factor` 始终为正值，导致所有沉默 agent 立场系统性向上漂移。批判立场的 agent 不会变得更批判。

5. **收敛检测已禁用**：模拟始终运行至 MAX_TICKS，无视系统是否已稳定。`CONVERGENCE_THRESHOLD = 0.05` 为僵尸参数。

6. **拐点阈值 0.1 无标定**：硬编码在 `report_agent.py:711`，不在 config.py。test8 中极化指数上涨 121% 但因无单轮 Δ > 0.1 而零拐点被检出（高假阴性）。

7. **无 agent 人口权重**：`OpinionSpreader.estimated_percentage`（如 45%）从未用于指标计算。所有 agent 等权重，与代表的人口比例无关。

8. **单次运行无置信区间**：LLM temperature 0.8 + 随机 speaker 选择 + LLM 生成 stance。单次运行的 x(t) 和 polarization 轨迹方差未知。

9. **样本标准差对小 N 的偏差**：使用 `statistics.stdev()` (N-1) 而非 population std (N)。在小样本（6-15 agent）下差异可观。

10. **Schema `le=1.0` 约束无数学保证**：CV 理论上可超出 1.0。虽然当前因 event entities 锚定在 5.0 不太可能触发，但无代码层面保护。违反时 Pydantic v2 会抛 ValidationError 导致模拟崩溃。

11. **Stance floor/ceiling 效应**：Agent 达到 1.0 或 10.0 后"卡住"，无法进一步变化，掩盖了进一步极端化的可能。系统不标记 floor/ceiling 命中事件。

12. **无群体级别代码侧聚合指标**：报告依赖 LLM 定性描述群体立场变化（如"中年女性群体立场变化"），无确定性代码计算的 per-group mean stance trajectory。

13. **无时间平滑/趋势分解**：逐 tick 裸指标值被直接使用。没有移动平均、指数平滑或趋势-噪声分解。LLM 随机性造成的 tick-to-tick 噪声被当作信号。

14. **指标无对应单元测试**：`calculate_global_metrics()`、`assess_risk()`、`identify_inflection_points()` 在 tests/ 中均无专项测试。
