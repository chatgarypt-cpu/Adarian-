### Known Issues (3 — deferred to v1.2.12)

1. **LLM overrides code-owned risk_level** (lines 69, 71, 137)
   - Code-owned: "低风险" / LLM: "中等偏高"
   - Root cause: prompt-only enforcement; LLM independently recalculates risk from raw metrics
   - Fix: add runtime validation in `save_markdown_report()` that scans for risk_level_label mismatch and flags LLM output. Or adopt the fallback markdown path as primary (the fallback generates correct output using the same code-owned values that feed the prompt).

2. **LLM fabricates risk types outside whitelist** (lines 75-77)
   - Code-owned: `["负面叙事聚合风险"]` / LLM: "品牌声誉风险", "舆论极化风险", "衍生争议风险"
   - Root cause: same as above — prompt tells LLM to use code-owned types, but LLM invents its own
   - Fix: runtime whitelist check in `save_markdown_report()` for risk type strings

3. **LLM exposes raw metrics in body** (lines 20, 22, 39-44, 51-55, 70-71, 134-137)
   - event_scale: 0.50, event_controversy: 0.35, polarization_index values, stance_delta values
   - Root cause: `build_full_report_context()` passes raw metrics to LLM context; prompt instructs translation but LLM copies them verbatim
   - Fix: pre-translate metrics before passing to LLM context, or add runtime scan for raw metric patterns

### Minor Issues (2)

4. **Internal labels leaked**: "CODE_OWNED_AGENT_STANCE_MATRIX" (line 49), "CODE_OWNED_INFLECTION_POINTS" (line 61) — should be stripped from consumer-facing output
5. **Old title string**: "事件概述" (line 16) — legacy template residue in LLM output
