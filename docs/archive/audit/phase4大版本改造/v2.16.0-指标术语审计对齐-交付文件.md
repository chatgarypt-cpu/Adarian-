### 3.1 附录保留英文括号

| 维度 | 内容 |
|------|------|
| **审计建议** | 去除中文名称后的英文括号标注（如 `事件规模（event_scale）`） |
| **实际选择** | 仅正文去除英文括号，**附录「数据说明」保留** |
| **选择理由** | 附录面向技术读者，保留英文字段名方便对照系统代码和 JSON 输入 |
| **对审计文件的影响** | 审计 §10.1 关于去除英文括号的建议，需限定范围为「正文」，附录豁免 |

### 3.2 不新增方法论免责声明

| 维度 | 内容 |
|------|------|
| **审计建议** | 审计 §9.4 & §12.2：在附录「数据说明」开头新增方法论免责声明（约150字，说明所有指标为工程性代理度量、无论文依据） |

| **对审计文件的影响** | 审计 §9.4 和 §12.2 的建议标记为「已评估，不执行」 |

> **PM 操作**：在审计文件中将 §9.4 和 §12.2 的状态更新为「不执行」，注明理由。


### 3.3 Tick 替换范围：正文/表格替换，技术说明保留

| 维度 | 内容 |
|------|------|
| **审计建议** | 审计多处使用「Tick」指代模拟轮次，未明确要求替换范围 |
| **实际选择** | **分层处理**：正文、表格模板、可视化示例中 Tick → 轮次；附录计算方法（公式中的 Tick t）、技术说明（tick_logs 文件名）中保留 Tick |

> **PM 操作**：确认审计文件中的 Tick 替换规则是否需增加「技术文档豁免」分层条款。如需要，在审计文件中补充。
