## 第 1 层：Owner Brief（人话摘要）

**1. 这轮干嘛？**

把现在三个打架的入口（`main.py` / `scheduler/` / `tools/probe_scheduler/`）收敛成一个：`python -m adarian`。同时把用户输入的原文（seed_text）存进 `simulation_dataset.json`，让下游报告技能不用读外部文件。

**2. 为什么现在做？**

- 当前 `main.py` 和 `scheduler/` 都在做类似的事，用户不知道用哪个
- 产品团队写报告 skill 时需要 seed 原文，现在只能绕道读文件，说明 dataset 缺字段
- 趁 v1.4 刚 closeout、v1.4.1 刚开工，入口整理的最佳时机

**3. 谁执行？**

Hermes 直接改（机械变动 + 文件搬迁，不需要 Codex dispatch）

**4. 会碰哪些文件？**

```
新建:
  adarian/__init__.py
  adarian/__main__.py      ← CLI 路由器
  adarian/run.py           ← 单次 pipeline
  adarian/serve.py         ← Web UI
  adarian/batch.py         ← 多模型并行
  adarian/inspect.py       ← 检查 batch 产物

修改:
  main.py                  ← 删 if __name__ CLI 部分，保留 main() 供库调用
  src/parser.py            ← parse() 加 seed_text 参数
  spec/dataset_fields.yaml ← 加 run_info.seed_text 条目

删除:
  scheduler/               ← 内容已迁入 adarian/
```

**5. 做完我看什么？**

```bash
python -m adarian --help          # 看到 run / serve / batch / inspect 子命令
python -m adarian run seeds/test8.txt  # 跑一轮，dataset 里有 seed_text
python -m adarian serve --port 9788    # 能打开浏览器
```

**6. 什么情况必须停？**

- 需要改 `src/phase1/` 到 `src/phase4/` 的调用链
- 需要改 `config.py` 的加载方式
- 需要改 `tools/probe_scheduler/` 内部

### 3. Goal & Boundary（目标与边界）

**Goal 1 — 入口收敛**

把 `scheduler/` 迁入 `adarian/`，`main.py` 降级为库入口。删除 `scheduler/`。

验收：
```bash
python -m adarian --help
  # → subcommands: run, serve, batch, inspect
python -m adarian run --help
python -m adarian serve --help
.venv/bin/python -m py_compile adarian/*.py
python -m adarian run seeds/test8.txt   # 跑一轮，产物正常
python -m adarian serve --port 9788     # 可访问
```

**Goal 2 — seed_text 补全**

`parser.parse()` 加 seed_text 参数，写入 `run_info.seed_text`。

验收：
```bash
python -m adarian run seeds/test8.txt
# → simulation_dataset.json 含 run_info.seed_text
# → 值等于种子文件原文
```

**Goal 3 — 统一启动脚本 + 双击入口**

新增 `adarian.sh`（含 `up` 子命令：一键启动 Web 后台 + 返回 CLI）、`start.command`（macOS 双击入口）。
`serve.py` 启动时用 Rich Panel 显示（匹配 StatusBar 画风）。

验收：
```bash
./adarian.sh up                        # Web 后台启动，CLI 可继续用
./adarian.sh serve                     # 仅 Web 控制台
# macOS: 双击 start.command 等效于 ./adarian.sh serve
```

**Goal 4 — batch 多世界实时面板**

`adarian/batch.py` 的 `execute_session()` 增加 Rich Live 显示，每秒刷新：
- 每 world 独立线程计时（`_world_start` dict）
- 从 `run.log` 实时抓取当前 Phase（`_phase_from_run_log()`）
- 运行中显示 ⏱ Phase + 耗时，完成后显示 ✓/✗ + 耗时 + dataset 状态
- 面板边框风格与 StatusBar 一致（`Panel(border_style="dim")`）

验收：
```bash
./adarian.sh batch --models qwen36-35b,ds --seed-path seeds/test8.txt --tag smoke
# 终端显示实时面板：2 world 各自 Phase/耗时实时更新
```

**Goal 5 — 显示修复**

- `[llm_diag]` 从 stdout 改到 stderr（`llm_client.py`：`print(..., file=sys.stderr)`），不污染 StatusBar
- Batch runner 子进程调用改为 `python -m adarian run ...`（避免依赖 `if __name__`）
