# 项目定位转变：从"预测"到"风险识别"

**日期**：2026-03-30
**参与者**：Claude Code + 用户
**性质**：关键性范式转变

---

## 一、核心转变

| | 旧定位（预测工具） | 新定位（风险识别） |
|--|------------------|------------------|
| 核心问题 | "会发生什么？" | "我们忽视了哪些风险？" |
| 评估标准 | 准确率 | 是否有新发现 |
| 系统价值 | 提供答案 | 提供镜子 |
| 失败模式 | 预测错了 | 没发现风险 |
| 与真实舆情关系 | 越准越好 | 不追求预测，追求视角 |

---

## 二、为什么这是范式转变而非程度转变

### 2.1 预测的不可行性

真实舆情被太多外部变量决定：
- 政策变化
- 明星/官方的突然声明
- 新的爆料
- 媒体算法放大
- 平台干预

任何模型都无法穷尽这些变量。追求"预测准确"是一条死路。

### 2.2 风险识别的价值

系统不需要预测对——只需要提供一个新的视角：

> "在我们都忙着骂譚竹的时候，系统指出：譚竹的沉默正在被解读为默认——这可能引发下一波舆情"

这种"镜子"的价值在于：**提供一个你没想过的角度**。

---

## 三、对系统设计的影响

### 3.1 Phase 4 报告重构

**当前输出**：
```markdown
## 舆情走向分析
- x(t) 序列：5.20 -> 5.17 -> ...
- 极化指数：0.34
- 风险等级：MEDIUM
```

**目标输出**：
```markdown
## 被忽视的风险

### 风险 1：譚竹的沉默正在被解读为默认
- 譚竹已连续 3 轮未主动发言
- 舆论场上开始出现"譚竹默认了"的猜测
- 风险级别：高
- 建议：关注譚竹下一步是否会打破沉默

### 风险 2：支持方声音在持续萎缩
- 理性支持者占比从 15% 下降到 8%
- 批评声音即将占据绝对主导
- 风险级别：中
- 建议：关注批评是否转向对譚竹的人身攻击
```

### 3.2 发言多样性

| 旧目标 | 新目标 |
|--------|--------|
| 多样性为了预测更准 | 多样性为了覆盖更多风险视角 |

系统要能模拟出"有人注意到了某个风险"，即使大多数人没注意到。

### 3.3 沉默检测（新增）

最有价值的风险往往藏在**没有人说的话里**。

**需要检测的沉默模式**：
- 某类角色连续多轮未发言
- 某个角度从未被讨论
- 支持方声音持续萎缩
- 对立观点突然消失

## 四、多 Agent 涌现的批判性思考

### 4.1 FD Model 的假设

FD Model 和多 Agent 模拟基于假设：
> 足够多的异质 agent，在足够多轮交互后，会涌现出真实的群体行为

### 4.2 这个假设的问题

| 假设 | 现实问题 |
|------|---------|
| Agent = 真实人类 | LLM 的角色扮演不等于真实心理 |
| 交互规则 = 真实信息传播 | 拓扑只是静态结构，真实舆情有媒体放大 |
| 多轮收敛 = 真实演化 | 真实舆情被外部事件随时打断 |
| 内部动力学主导 | 真实舆情更多被外部事件驱动 |

### 4.3 涌现的一定合理吗？

**答案：不一定是**。

LLM 模拟的是"基于文本统计规律的角色扮演"，不是真实人类的认知机制。

涌现出来的行为可能是**数学上合理，但现实上可疑**的。

### 4.4 系统的真正价值

不是"预测真实舆情"——那是不可行的。

价值在于：

1. **压力测试**：极端假设下，系统会怎么演化？哪里会崩溃？
2. **情景规划**：如果某类声音主导了，舆情会往哪个方向走？
3. **反直觉发现**：哪些因素会导致意想不到的极化？

**前提是**：清楚地知道系统在模拟什么——不是"人类行为"，而是"基于特定规则的符号演化"。

## 五、GraphRAG 和 IPC 模型的价值重估

### 5.1 GraphRAG

| 原目标 | 新目标 |
|--------|--------|
| 减少发言同质化 | 扩大风险视角覆盖 |
| 让 agent 说不重复的话 | 让 agent 能覆盖更多风险角度 |

### 5.2 IPC 模型重构

| 原目标 | 新目标 |
|--------|--------|
| 修复 stance 计算诡异 | 让 agent 的立场演化更可信 |
| 追求预测准确 | 追求风险识别的逻辑一致性 |

### 5.3 优先级调整

| 优先级 | 内容 | 理由 |
|-------|------|------|
| P0 | Phase 4 报告重构 | 直接服务新定位 |
| P1 | GraphRAG | 扩大风险覆盖视角 |
| P2 | IPC 模型重构 | 提高逻辑可信度 |
| P3 | 简化 Bounded Confidence | 可选，优先级低 |

---

## 六、一句话总结

> 项目最重要的不是让预测更准，而是让人们在舆情发展初期，就能通过系统看到那些**"我们都在忽视的风险"**——这是从"答案机器"到"思维镜子"的转变。
