# 🧠 项目上下文记忆文档（Checkpoint）

## 📌 项目名称

多智能体舆情推演系统（Agent-based Public Opinion Simulation）

---

## 🎯 项目目标（当前版本语义）

构建一个可运行的多智能体仿真系统，用于模拟舆情在不同群体中的传播、演化与极化过程。

系统具备：

* 多角色（agent）建模
* 社交关系建模
* 观点动态演化（stance update）
* 多轮传播（tick-based simulation）
* 最终舆情分析报告生成

---

## 🏗️ 当前架构（v1.1.x）

系统分为四个阶段：

### Phase 1：事件解析 + Agent建模

* 提取事件实体
* 构建 opinion groups（传播者）
* 为每个 group 生成 persona（LLM）
* 初始化 stance / susceptibility

---

### Phase 2：社交网络构建

* 构建传播拓扑（graph）
* 确定 agent 之间的关注关系

---

### Phase 3：多轮舆情传播（核心）

每轮 tick 包含：

1. Speaker Selection（关键）

   * Adaptive Speaker Selector（已实现）
   * 决定哪些 agent 发言
   * 非全员发言（已验证）

2. Context Construction

   * followed posts（裁剪 ≤3）
   * agent history（裁剪 ≤2）

3. LLM 发言生成

   * 仅 selected speakers 调用模型
   * silent agents 不调用模型

4. 状态更新

   * stance delta（受 susceptibility 控制）
   * silent_exposure_drift

---

### Phase 4：报告生成

* 汇总全局演化结果
* 输出分析报告（LLM）

## 📊 当前系统行为特征（非常关键）

### 1. 调度行为（健康）

* 发言人数非固定
* 示例：

  * 6 → 7 → 5 → 5 → 5
* 系统进入收敛状态

---

### 2. 演化特征（初步合理）

* stance 逐步变化（非剧烈跳变）
* 群体出现分化趋势
* 极化指数略上升（正常）

---

### ⚠️ 3. 已观察到的问题（下一阶段重点）

#### （1）语义收敛（Semantic Collapse）

* agent 输出开始重复
* 固定表达模式：

  * “非遗/匠心/成本”
  * “公开成本明细”
* 多轮后表达多样性下降

---

#### （2）单向极化（Monotonic Drift）

* 某些群体持续强化立场：

  * 支持者越来越支持
  * 反对者越来越反对
* 缺少反向扰动

---

#### （3）群体发言不均（潜在问题）

* 高频发言群体：

  * 忠实客户 / 支持者 / 价格敏感群体
* 低活跃群体：

  * 中立派 / 观察者 / 批评派

→ 存在“话语垄断”趋势

---

#### （4）性能瓶颈（明确）

* Phase 3：

  * 串行 LLM 调用（主要瓶颈）
* Phase 1：

  * persona 生成耗时极高（最大耗时）
