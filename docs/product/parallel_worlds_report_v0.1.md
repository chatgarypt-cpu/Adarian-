## 一句话结论

**6 个模型对同一事件的推演，得出了 3:3 的风险等级分歧。其中一项关键风险——透明度风险——只有 1 个模型看到了。**

## 1. 风险等级：3:3 分裂

| 等级 | 模型 | 个数 |

| 🔴 高风险 | qwen3-30b-tke, qwen36-35b, ds | 3 |

**这不是系统误差。** 每个模型独立跑通了完整的 Phase 1→2→3→4 管线，分别建构了各自的舆论场。同一个事件在三组模型眼中被判断为高风险、在三组眼中被判断为中风险。

**对客户来说这意味着：** "风险等级"不是一个数，是一个区间。如果你的 PR 团队只用了单一模型做推演，你看到的可能只是这个区间里的一半。

## 2. 关键分歧：被忽略的透明度风险

| 风险类型 | 命中数 | 命中的模型 |
|---------|:------:|-----------|
| 负面叙事聚合风险 | 6/6 | 全部 |
| 平台治理舆情外溢风险 | 6/6 | 全部 |
| 二次传播议题溢出风险 | 2/6 | qwen3-30b-tke, qwen36-35b |
| 群体极化碎片化风险 | 3/6 | qwen3-80b-tke, minimax, qwen-35-122b-sg |
| **透明度风险** | **1/6** | **ds** |

**这是整份报告唯一值得高亮标注的数字。**

5 个模型认为这个事件不存在透明度风险。只有 ds 认为存在。如果客户只用了单一模型推演——大概率是 qwen36-35b（当前主力）——ta 的报告中不会出现"透明度风险"这个词。

**但 ds 看到了什么？** 分析 ds 的推演数据可以发现，ds 构建的舆论群体中包含"传统保守网民"和"女性权益倡导者"，这些群体的关注焦点不在于营销文案本身，而在于品牌方的**信息披露透明度和价值观一致性**。这个风险维度被其他 5 个模型忽略了。

**客户付钱的时刻就在这里：** 你不知道你漏了什么，直到你看到了那个 outlier。

**qwen3-30b-tke** 建构了一个包含 3 个反对群体的舆论场——"饭圈文化批判者"（+2.0）、"社会伦理守望者"（+1.5）、"理性消费者代表"（+2.5）。这些群体的 stance 都偏低，使整体立场均值压到了 4.03。

**两个极端之间的差异，就是多模型推演的信息增量。**

## 4. 方法论

传统舆情推演使用单一模型，一次运行，一个结论。

本报告采用 **平行世界推演方法论**：

```
同一事件文本
  ├── World 1: qwen3-30b-tke → 高风险, 3类风险
  ├── World 2: qwen3-80b-tke → 中风险, 3类风险
  ├── World 3: qwen36-35b    → 高风险, 3类风险
  ├── World 4: minimax       → 中风险, 3类风险
  ├── World 5: qwen-35-122b  → 中风险, 3类风险
  └── World 6: ds            → 高风险, **4类风险（含透明度风险）**
```

每个世界是完全独立的推演——独立建构实体、独立生成群体、独立模拟互动、独立研判风险。模型间的差异不是技术噪声，而是 **不同认知框架下的舆论建构差异**。

## 5. 结论

### 给客户的答案不是"风险高不高"

传统产品给的答案：
> "风险等级：中。建议关注负面舆论。"

你的产品给的答案：
> "6 个模型中有 3 个判定为高风险、3 个判定为中风险。5 个模型识别了 3 类风险，1 个模型额外识别了透明度风险——这个维度其他模型没有观察到，建议人工复核。"

### 产品核心价值

**不是预测未来，而是暴露盲区。**

任何单模型推演都只能给出一个模型框架下的风险判断。但舆论是建构的——不同模型建构不同版本的现实。平行世界推演让客户看到风险判断的**置信区间**，而不是一个**伪精确的单一数字**。
