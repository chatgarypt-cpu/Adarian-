# 附录 A：数据说明与方法论

## 一、项目说明

本报告基于宏微观结合的舆情推演系统 Adarian 生成。系统通过让多个具有独立人格的 LLM 驱动智能体在微型社交网络中进行多轮交互，观察群体立场的涌现与演化，最终提炼相关舆情的风险研判与对策建议。

## 二、核心指标

### （一）事件规模

由 LLM 在事件解析阶段根据输入文本中的主体数量、社会领域跨度等要素综合打分，经 Compiler 归一化至 0-1 范围。值越高代表事件越不限于单一主体，可能波及更大范围。

**来源**：LLM 生成（Phase 1 EntityExtractor）→ Compiler 归一化

### （二）事件争议性

由 LLM 在事件解析阶段根据事件涉及的伦理边界模糊性、价值判断分歧度等要素综合打分，经 Compiler 归一化至 0-1 范围。值越高代表公众对如何定性事件越难达成共识。

**来源**：LLM 生成（Phase 1 EntityExtractor）→ Compiler 归一化

### （三）模拟立场均值

每一轮模拟中，取全部智能体当前立场分数的算术平均。

```python
x(t) = mean(stance_1, stance_2, ..., stance_n)
```

其中 stance 范围为 0（完全反对事件主体）到 10（完全支持），5 为中立。报告中出现的"模拟立场均值"即最后一轮的 x(t)。持续低于 4.5 说明舆论压力显著。

**来源**：确定性计算（`tick_simulation.py` → `get_x_t_sequence()`）

### （四）负向趋势

模拟期间立场均值从起点到终点的下降幅度，变化数值量为 0-9+。

```python
negative_trend = max(0, x(0) - x(T))
```

其中 x(0) 为第一轮立场均值，x(T) 为最后一轮立场均值。≥0.4 即存在可监测的舆论负向走向。

**来源**：确定性计算（`risk_analyzer.py` → `_compute_signals_internal()`）

### （五）模拟极化指数

各群体立场的分散程度，数值范围为 0-1 ，取值越高意味着观点越两极分化而非温和多元。

```python
mean_stance = mean(all_stances)
std_stance = stdev(all_stances)
polarization_index = std_stance / mean_stance   # 当 mean_stance > 0
```

≥0.30 即视为显著极化。

**来源**：确定性计算（`tick_simulation.py` → `calculate_global_metrics()`）

### （六）关键群体最大负向迁移

全部智能体中立场偏移最大者的下降幅度，变化数值量为 0-9+。反映事件对特定群体的冲击烈度。

```python
for each agent:
    shift = max(0, agent.initial_stance - agent.final_stance)
max_negative_shift = max(all_shifts)
```

以第一轮末的立场为起点、最后一轮末的立场为终点。≥1.2 为可感知冲击，≥2.0 属于强冲击。

**来源**：确定性计算（`stance_analyzer.py` → `max_negative_shift()`）

### （七）模拟轮次

智能体在微型社交网络中交互的总轮数，每轮所有智能体依次发言并更新立场。

**来源**：纯计数

### （八）群体立场变化

每个参与群体的立场变化情况，包括起始立场、最终立场、变化幅度和变化方向（上升/下降/稳定）。

```python
delta = final_stance - initial_stance
attitude = "rising" if delta > 0.01 else "declining" if delta < -0.01 else "stable"
```

**来源**：确定性计算（`stance_analyzer.py` → `build_agent_stance_matrix()`）

### （九）风险等级

综合上述信号的确定性阈值矩阵判定，分为低、中、高、重大四个等级，无 LLM 参与。

```python
# 信号收集
medium_signals = [
    final_x <= 4.7,                    # 立场均值偏低
    negative_trend >= 0.4,             # 存在可监测的负向走向
    final_pol >= 0.30,                 # 极化显著
    max_negative_shift >= 1.2,         # 存在群体负向迁移
    event_scale >= 0.7 and event_controversy >= 0.7,  # 高敏事件先验
    sensitive_context_hit,             # 敏感治理语境命中（非通用受众或高极化）
]

high_signals = [
    final_pol >= 0.45 and (negative_trend >= 0.4 or max_neg_shift >= 1.2),
    max_neg_shift >= 2.0 and sensitive_context_hit,
    final_x <= 4.0 and negative_trend >= 0.5,
    event_scale >= 0.7 and event_controversy >= 0.7 and final_pol >= 0.40,
]

critical_ready = (
    final_x <= 3.0
    and final_pol >= 0.45
    and max_neg_shift >= 2.5
    and (event_scale >= 0.7 or event_controversy >= 0.8 or sensitive_context_hit)
)

# 优先级判定
risk_level = CRITICAL if critical_ready
             else HIGH if any(high_signals)
             else MEDIUM if any(medium_signals)
             else LOW
```

**来源**：确定性算法（`risk_analyzer.py` → `assess_risk()`）

### （十）风险类型分类

采用 28 类风险类型分类体系，由 LLM 分析模拟数据后从完整分类中选出最相关的 3 类。分类体系为预定义但分类决策由 LLM 做出，受 LLM 判断波动影响。

**来源**：LLM 生成（`classifier.py` → `RiskClassifier.classify()`）

## 三、风险类型说明

本报告采用 28 类风险类型分类体系，覆盖 6 个一级风险域。风险类型由 LLM 分析模拟数据后从以下完整分类中选出最相关的 3 类。

### （一）治理信任类

| 风险类型 | 典型场景 |
|----------|---------|
| 监管信任风险 | 监管动作被质疑、被认为失职或被指控为利益相关方 |
| 执法公信风险 | 执法/警察行为引发冲突或被质疑程序 |
| 处置透明度风险 | 处置过程信息不公开、回应迟缓或被怀疑隐瞒 |
| 舆论问责升级风险 | 舆论从质疑事实升级为追责、问责具体官员 |
| 政策解释压力风险 | 政策被误读、引发广泛担忧或激烈争论 |

### （二）公共安全与民生类

| 风险类型 | 典型场景 |
|----------|---------|
| 食品与产品安全治理风险 | 食品/产品质量问题或品牌信任危机 |
| 校园与未成年人保护风险 | 校园暴力、未成年人侵害、家校冲突 |
| 公共安全感风险 | 公共场所安全事件、突发治安、群体性事件 |
| 民生保障与弱势群体保护风险 | 弱势群体保障、困难群众、欠薪、扶贫 |
| 公共卫生事件风险 | 传染病防控、医疗资源、疫苗、医疗事故 |
| 环境与生态安全风险 | 污染、生态破坏、环评、气候争议 |

### （三）传播演化类

| 风险类型 | 典型场景 |
|----------|---------|
| 负向叙事聚合风险 | 负面叙事快速聚合，话题被反复放大 |
| 群体极化与舆论撕裂风险 | 群体立场极度分化、对立尖锐 |
| 次生传播与议题外溢风险 | 议题从原事件外溢、引发次生讨论 |
| 谣言与事实混淆风险 | 谣言与事实并存、真相难以澄清 |

### （四）信息安全与意识形态类

| 风险类型 | 典型场景 |
|----------|---------|
| AI/深度伪造滥用风险 | AI 合成、伪造视频/语音/图文被传播或滥用 |
| 数据与网络安全关注风险 | 数据泄露、网络安全事件、平台漏洞 |
| 意识形态、价值观与涉外叙事风险 | 境外信息操纵、涉外叙事、意识形态对冲 |
| 科技伦理与 AI 治理风险 | 算法歧视、科技伦理、关键基础设施技术风险 |

### （五）治理执行压力类

| 风险类型 | 典型场景 |
|----------|---------|
| 公共服务回应压力风险 | 公共服务供给不足、回应能力受压 |
| 基层治理承压风险 | 街道/社区/基层一线承压 |
| 跨部门协同与责任边界风险 | 部门协同失败、责任互相推诿 |
| 平台治理与消费争议外溢风险 | 平台/消费争议外溢为公共事件 |

### （六）经济金融类

| 风险类型 | 典型场景 |
|----------|---------|
| 金融市场波动风险 | 股市/债市/汇市剧烈波动或危机信号 |
| 地方债务与财政风险 | 地方债、城投债、财政可持续性 |
| 就业与劳动权益风险 | 大规模裁员、欠薪、劳资纠纷 |
| 房地产与资产价格风险 | 房价、烂尾、断供、地产债务 |
| 金融诈骗与非法集资风险 | P2P、虚拟货币、养老诈骗、非法集资 |

本次推演中触发的风险类型在正文"风险研判"章节中列出。

## 四、推演方法

Adarian 系统在每轮推演中：

1. **事件解析**（含 LLM 调用）：从输入文本中提取关键实体、关系与舆情要素，LLM 生成事件摘要，并对事件规模和争议性进行初始打分，经 Compiler 归一化。
2. **群体构建**（含 LLM 调用）：为各方配置独立的 LLM 驱动智能体，赋予差异化的人格、动机和沟通风格。
3. **舆论演化**（确定性模拟）：智能体在微型社交网络中交互，每次交互后立场因社会影响算法而发生变化，形成舆论演化轨迹。
4. **风险研判**（确定性 + LLM）：通过确定性信号矩阵判定风险等级（无 LLM），再由 LLM 从 28 类预定义风险类型中选出最相关的 3 类。

本报告正文即为多组平行推演结果经交叉验证后的最终结论。

## 五、原始数据说明

本报告基于完整的仿真数据集（simulation_dataset.json）生成，该数据集包含事件实体、意见群体分布、逐轮交互记录、立场演化轨迹等原始模拟信息。如需访问完整数据集或了解数据字段规格，可联系 Adarian 团队。
