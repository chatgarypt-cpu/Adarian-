# Writing Guide

> **生成方式**：逐章独立生成，每章写完后立即统计字数、达标后再写下一章（A 版无字数要求，自由生成后通读润色即可）。严禁一次性生成四章全文。**生成前必读**：确认用户选择的版本（A/B/C），严格参照下方字数表。

将 appendix_b.json 转化为面向政府决策者的舆情风险研判文字报告。

## 结构

标题: `[事件名称]舆情风险研判`（一级标题 `# `）

四章正文（每章标题使用二级标题 `## ` 语法，章内小节使用 `### ` 三级标题）:
1. `## 一、舆情概要`
2. `## 二、演化分析`
3. `## 三、风险研判`
4. `## 四、对策意见`

**强制要求**：所有章节标题必须使用 Markdown 标题语法（`## ` / `### `），禁止使用纯文本伪标题（如 `一、舆情概要` 或 `（一）...` 不加 `#` 前缀）。这确保报告在 Markdown 渲染器中正确显示层级结构。

### 子级标题编号规范（强制）

章内子级标题必须采用中文数字分级编号，按层级依次为：

| 层级 | 编号格式 | Markdown 语法 | 示例 |
|------|---------|--------------|------|
| 第一层（章标题） | 一、二、三、四 | `## ` | `## 三、风险研判` |
| 第二层（节标题） | （一）（二）（三） | `### ` | `### （一）负向叙事聚合风险（高风险）` |
| 第三层（小节） | 1. 2. 3. | 正文段落首行 | `1. 具体措施一` |
| 第四层 | （1）（2）（3） | 正文内嵌 | `（1）第一阶段……（2）第二阶段……` |

**强制规则**：
- 当章内存在多条并列内容（如风险研判章的多条风险、对策意见章的多条对策）时，每条必须使用 `### （一）...` / `### （二）...` / `### （三）...` 格式的三级标题
- 编号必须从"（一）"开始连续递增，禁止跳过或使用其他序号体系（如 A/B/C）
- C 版（详细阅读）必须使用子级标题编号；B 版（便捷速览）因字数限制可不设子标题，但如有子标题则必须遵守此规范

T4 拼接附录A + 附录B。

## 字数规格

调用时询问用户选择 A 版、B 版或 C 版。每章独立控制字数，达标后再写下一章（A 版无字数要求，自由生成）。

| 章节 | A版（自由生成） | B版（便捷速览） | B版建议首稿 | C版（详细阅读） | C版建议首稿 |
|------|----------------|----------------|------------|----------------|------------|
| 一、舆情概要 | 不限 | 200-300字 | ~250字 | 400-600字 | ~500字 |
| 二、演化分析 | 不限 | 450-650字 | ~550字 | 900-1300字 | ~1100字 |
| 三、风险研判 | 不限 | 400-600字 | ~500字 | 1000-1400字 | ~1200字 |
| 四、对策意见 | 不限 | 180-280字 | ~230字 | 1000-1400字 | ~1200字 |
| 正文合计 | 不限 | 1400-1500字 | ~1450字 | 3800-4000字 | ~3900字 |

A版对策意见：自由展开，建议 2-3 条核心对策。
B版对策意见：确认风险 ≤3 条时全部实质性展开；>3 条时展开最核心 2-3 条，其余仅标等级。每条展开必须含风险锚定 + 责任主体 + 行动方向 + ≥1 条具体措施，禁止一句话敷衍（如"XX风险等级为高风险，建议防范"）。
C版对策意见：所有确认风险均完整展开（A+B+C）。

## 逐章生成流程

每章走"生成→自估字数→调整→复检"流程：

1. **生成**该章初稿，首稿锚定建议字数中位数
2. LLM **自行统计**该章中文字数（含中文标点），与目标范围对比
3. 若低于下限则按差值扩充，若超出上限则按差值删减
4. 调整后重新统计字数 → **达标后**进入下一章

四章全部达标后，通读全文做一次文风统一润色（仅调整过渡衔接和用词一致性，不改变各章字数）。

## 各章写作规则

### 一、舆情概要

- 基于 seed_input + LLM 对现实舆情事件的了解，概括写作
- 禁止照搬照抄 seed_input 原文，禁止出现任何模拟指标、推演参数、仿真术语
- 以具体日期、事件核心矛盾、实际引发的社会争议为主语开篇
- 叙述事件经过、媒体报道情况及真实社会舆论反应（如话题阅读量、转发量、网民情绪方向等）
- 末句以"当前，网络舆情主要聚焦……"收束，点明舆论核心议题
- 仅就真实舆情事件本身进行概要写作，不包含任何模拟参数或推演数据

### 二、演化分析

- 从 appendix_b.evolution_analysis 翻译为自然语言
- 开头允许一句"以真实现实事件发展为基础，模拟推演显示……"交代数据来源
- 禁止出现立场分、极化指数、群体数量、轮次编号、百分比等模拟指标
- 定性判断必须可追溯到 appendix_b.json 中对应字段

### 三、风险研判

- 从 appendix_b.risk_assessment 翻译为自然语言
- 禁止出现"推演""模拟""world""跨组""一致显示""识别该风险""仿真"等推演/仿真术语
- 禁止堆砌模拟指标（立场分、极化指数、群体数量、轮次编号、百分比）
- 以自然语言解释风险: 定性判断 + 现实传导链条 + 指向主体
- 每条含风险标签、因果链、影响范围
- 文风: 平实、流畅、准确，书面语为主，避免口语化或修饰性过强词汇
- 内容权威、稳重、专业、可读性强
- 定性判断必须可追溯到 appendix_b.json 中对应字段

### 四、对策意见

- 从 appendix_b.countermeasures 翻译为自然语言
- A+B+C 组织: 风险锚定 + 责任主体 + 行动方向
- 禁止"短期/中期/长期"三段式结构

## 文风

- 当代舆情写作书面语，行文平实、流畅、准确
- 避免口语化或修饰性过强词汇
- 内容权威、稳重、专业、可读性强
- 优先使用具体主语和行动动词
- 避免 AI 填充词: "值得注意的是"、"深入探讨"、"至关重要"、"标志着"、"未来可期"
- 避免泛泛赞美、广告语感、对话残迹

## 常见违规速查

提交前自查:

| # | 违规 | 严重度 | 修正 |
|---|------|--------|------|
| 1 | "标志着"、"具有里程碑意义" | A1 fatal | 替换为"表明"、"显示出" |
| 2 | "值得注意的是"、"不难看出" | A3 medium | 删除填充词，直接陈述 |
| 3 | world_0/world_2 等模拟内部标识符 | B1 fatal | 用现实主体替代: "该事件"、"相关讨论" |
| 4 | 立场分、极化指数、百分比等数值 | B1 fatal | 用定性描述: "显著分化"、"小幅上升" |
| 5 | 第一章出现模拟/推演术语 | B2 fatal | 舆情概要仅基于真实舆情写作 |
| 6 | 第三章出现"推演""模拟""跨组""一致显示" | B11 fatal | 改为自然语言现实风险分析 |
| 7 | 第一章照搬 seed_input 原文 | B12 medium | LLM 概括，以自身知识补充 |
| 8 | 过度使用中文破折号（>10个） | A4 medium | 部分替换为逗号或句号 |
| 9 | "短期/中期/长期"三段式对策 | B6 fatal | 用 A+B+C 结构 |
