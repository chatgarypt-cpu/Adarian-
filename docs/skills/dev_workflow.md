# Adarian MVP 开发规范与工作流程（Claude Code 操作手册）[历史存档]

## 文档概述

本文档定义了 Adarian MVP 项目的版本管理规范、迭代流程和任务日志管理机制。作为 Claude Code，你必须严格遵守本规范执行所有开发任务。

---

## 版本命名规范

### 版本号格式：`vX.Y.Z`

- **X（主版本号）**：重大架构变更（如引入 AD 快模块、SEIR 慢模块）
- **Y（次版本号）**：功能迭代（如新增 Phase 0、重构 Phase 1）
- **Z（修订号）**：Bug 修复、小优化

### 当前项目生命周期

```
v1.1.x - MVP 阶段（微观涌现验证）
  ├── v1.1.0 - 基线版本（Phase 1-4 基础功能）
  ├── v1.1.1 - 引入实体提取与基于实体的 Agent 生成
  ├── v1.1.2 - Agent 个体差异化与确认偏差注入
  └── v1.1.3 - 社交网络拓扑优化

v2.0.x - 扩展阶段（引入 AD 快模块 + GraphRAG）
  └── 待规划

v3.0.x - 完整阶段（引入 SEIR 慢模块 + 前端可视化）
  └── 待规划
```

## 核心工作流程

### 阶段 1：接收迭代任务

当用户提供新的迭代需求时，你需要：

1. **读取迭代文档**：`docs/iterations/vX.Y.Z_xxx.md`
2. **理解修复目标**：明确本次要解决什么问题
3. **识别文件变更范围**：哪些文件需要新增、修改、保持不变

---

在 `docs/iterations/TASK_LOG.md` 中记录任务开始：

---

### 阶段 3：执行代码修改

严格按照迭代文档中的"详细修改指令"执行：

#### 规则 1：最小化修改原则
- ✅ 只修改迭代文档中明确列出的文件
- ❌ 不要"顺手"优化其他未列出的代码
- ❌ 不要修改标注为"✅ 无变更"的文件

#### 规则 2：代码注释规范
每个新增或修改的函数必须包含：
```python
def new_function():
    """
    功能说明：做什么

    为什么这样做（Why）：
    - 原因 1
    - 原因 2

    新增于：v1.1.1
    修改历史：
    - v1.1.1: 初始实现
    """
```

#### 规则 3：向后兼容
- 如果修改了数据结构，必须确保旧版本的输出文件仍能被读取
- 如果无法兼容，必须在迭代文档中明确标注"Breaking Change"

## 异常处理规范

### 情况 1：迭代文档不清晰

如果迭代文档中的指令模糊或矛盾，你必须：

1. **停止执行**，不要猜测用户意图
2. **在任务日志中记录**：
   ```markdown
   ## [YYYY-MM-DD HH:MM] 任务暂停：vX.Y.Z

   **原因**：迭代文档存在以下不清晰之处：
   1. 问题描述
   2. 问题描述

   **需要用户澄清**：
   - 问题 1
   - 问题 2

   **状态**：⏸️ 等待用户反馈
   ```
3. **向用户提问**，等待明确指令后再继续

---

### 情况 2：代码修改导致测试失败

如果修改后运行测试失败：

1. **不要强行提交代码**
2. **在任务日志中记录**：
   ```markdown
   ## [YYYY-MM-DD HH:MM] 任务遇到问题：vX.Y.Z

   **问题**：修改后测试失败

   **失败的测试**：
   - test_phase1.py::test_archetype_count

   **错误信息**：
   ```
   AssertionError: Expected 5 archetypes, got 7
   ```

   **初步分析**：
   - 可能原因 1
   - 可能原因 2

   **建议方案**：
   - 方案 1
   - 方案 2

   **状态**：⏸️ 等待用户决策
   ```
3. **向用户报告**，等待指示

- [ ] 我更新了总变更日志

- [ ] 我在任务日志中提供了"下一步建议"

---

## 核心原则（必须遵守）

1. **文档驱动开发**：所有修改必须基于迭代文档，不得凭空发挥
2. **最小化修改**：只改必须改的，不做"顺手优化"
3. **向后兼容**：除非明确标注 Breaking Change，否则必须兼容旧版本
4. **透明化记录**：所有操作必须在任务日志中留痕
5. **主动沟通**：遇到不清晰的地方，立即停止并向用户提问
