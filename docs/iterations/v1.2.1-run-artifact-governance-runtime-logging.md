## 目标

本轮执行最小运行产物治理：把 `main.py` 主链输出从 root `outputs/` 改为 run 级隔离目录，接入现有 `RuntimeLogger`，补齐 `run.log`、`timing_summary.json`、`run_meta.json`，并修复 `final_report.json` / `final_report.md` 输出契约。

权威 run 目录：

```text
outputs/runs/<run_id>/
```

`run_id` 格式：

```text
<seed_stem>_<YYYYMMDD_HHMMSS>
```

示例：

```text
outputs/runs/test7_20260425_153012/
```
