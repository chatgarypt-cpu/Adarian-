## 🎯 本次修复目标

### 问题 1：Agent 发言严重同质化（逐字重复）

**现象**：
- Agent #7（品牌质疑者）连续 5轮发言完全一字不差："花西子到底是不是日本品牌？真相在哪？"
- Agent #5（李佳琦粉丝）连续 5 轮发言仅换几个字："李佳琦说的对，国货不易，花西子值得支持。"
- Agent #4（花西子粉丝团）、Agent #6（价格敏感消费者）、Agent #8（理性评论者）均存在高度相似的重复发言

**根因分析**：

| 根因 | 严重程度 | 说明 |
|------|---------|------|
| 根因1：opinion_spreader 每轮只看到core节点的Tick 0 固定发言 | 🔴 致命 | `saw_posts_from` 每轮完全相同，输入不变 → 输出不变 |
| 根因2：Agent 不知道自己之前说过什么 | 🟡 严重 | Prompt 中无历史发言信息，无法避免重复 |
| 根因3：Agent 人设维度太少，Prompt 缺乏差异化 | 🟡 严重 | 只有 `description` + `communication_style` 两个维度，不同群体说话方式趋同 |

**解决方案**：

| 任务 | 对应根因 | 方案 | 优先级 |
|------|---------|------|--------|
| 任务A：拓扑信息流修复 | 根因1 | opinion_spreader 在Tick 2+ 能看到拓扑连接的 peer 上轮发言 | 🔴 P0 |
| 任务B：历史记忆注入 | 根因2 | 从 `self.agent_comments` 读取历史发言注入 Prompt | 🟡 P1 |
| 任务C：Agent 人设增强 + Prompt 重构 | 根因3 | OpinionSpreader 新增 6 个人设字段，Phase 3 Prompt 全面重构 | 🟡 P1 |

### 任务 A：拓扑信息流修复（P0）

**功能**：让 opinion_spreader 在 Tick 2+ 能看到拓扑连接的其他 opinion_spreader 的上轮发言，而不是每轮只看到 core 节点的 Tick 0 固定发言。

**当前信息流（有问题）**：
```
Tick 1: Agent#4 看到 [花西子Tick0]
Tick 2: Agent#4 看到 [花西子Tick0]           ← 完全一样
Tick 3: Agent#4 看到 [花西子Tick0]           ← 完全一样
```

**修复后信息流**：
```
Tick 1: Agent#4 看到 [花西子Tick0]
Tick 2: Agent#4 看到 [花西子Tick0] + [Agent#6Tick1发言] + [Agent#8 Tick1发言]
Tick 3: Agent#4 看到 [花西子Tick0] + [Agent#6 Tick2发言] + [Agent#8 Tick2发言]
```

**修改文件**：`src/phase3_tick_simulation.py`

**修改点 1**：`get_followed_comments()` 方法

```python
def get_followed_comments(self, agent_id: int, tick: int, max_posts: int = None) -> List[Tuple[int, str]]:
    """获取某agent 能看到的发言

    信息来源：
    1. 拓扑连接的 core 节点（事件实体）的 Tick 0 发言（始终可见）
    2. 拓扑连接的 peer 节点（其他 opinion_spreader）的上轮发言（Tick 2+ 可见）

    Args:
        agent_id: agent ID
        tick: 当前轮次
        max_posts: 最多获取的发言数

    Returns:
        List of (source_agent_id, comment) tuples
    """
    max_posts = max_posts or config.MAX_POSTS_PER_TICK

    # 获取该 agent 拓扑连接的节点
    followers = list(self.G.successors(agent_id))

    comments = []

    for followed_id in followers:
        if followed_id not in self.agent_comments:
            continue
        if not self.agent_comments[followed_id]:
            continue

        followed_node = self.phase2_output.nodes[followed_id]

        if followed_node.entity_category == "event_entity":
            # core 节点：始终返回 Tick 0 发言
            comments.append((followed_id, self.agent_comments[followed_id][0]))

        elif followed_node.entity_category == "opinion_spreader" and tick >= 2:
            # peer 节点：Tick 2+ 返回上轮发言（最后一条）
            comments.append((followed_id, self.agent_comments[followed_id][-1]))return comments[:max_posts]
```
