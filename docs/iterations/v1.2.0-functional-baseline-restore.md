### 问题描述

**根本问题**：

- 文档状态领先或偏离源码状态

- 输出产物混乱，root outputs 被多次覆盖
- E2E 证据链不清晰
- runtime logger / output manager 等可观测能力曾在文档中被描述，但当前实际主链没有完整落盘
- 多个模型 / agent / prompt 并行审计后，发现当前最重要的问题不是主链业务逻辑，而是 baseline 证据链与产品定义缺位
