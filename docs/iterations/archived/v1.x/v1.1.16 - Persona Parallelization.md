## 🎯 本次迭代目标

### 问题描述

* 当前存在的问题：

  * 虽然 v1.1.14 / v1.1.15 已完成事实层、结构层与规则层的拆分，但 persona 相关字段仍与群体结构生成强耦合
  * 表达层字段（如 persona_name、occupation、personality、motivation、typical_phrases 等）本质上不属于结构规划，而属于表达增强层
  * persona 生成与 group skeleton 生成混在一起，会导致：

    * Prompt 变长
    * 字段互相干扰
    * 结构稳定性被表达多样性拖累
  * 当前 persona 生成没有并发能力，后续若 agent/group 数量提升，会直接拖累 Phase 1 性能
* 影响范围：

  * Phase 1 生成效率
  * persona 多样性
  * 未来百级 agent 模板化扩展能力
  * 后续 Group Template → Agent Instantiator 的演进路径
* 是否为结构性问题（是/否）：**是**

---

### 解决目标

* 本次希望达成的效果：

  * 将 persona 相关字段彻底从 Group Planner 中剥离
  * 新增独立 Persona Writer 作为 Phase 1 的表达层
  * 支持对多个 group skeleton 并发生成 persona
  * 保持对外 `Phase1Output` 兼容
  * 为未来群体模板化与规模化实例化预留接口
* 是否允许 breaking change：**否**
* 本次是否涉及架构调整（是/否）：**是**

---

# 🧠 架构变更说明（新增关键模块）

### 当前结构问题

* 当前 Phase 1 虽然已经拆出 Extractor / Planner / Rules Engine，但表达层还未独立
* Group Planner 仍承担了部分 persona 责任，导致“结构规划”和“表达增强”混在一起
* persona 字段不独立，后续无法：

  * 单独调优 diversity
  * 单独切换轻量 persona 模式
  * 单独做并发生成
* 当前问题已在你的重构目标中被明确指出：Phase 1 不应越界到 persona / occupation / personality / motivation / typical_phrases 等表达层内容，这些应延后或独立。

---

### 目标结构（本次之后）

列出模块划分：

* **Module A：Entity Extractor（事实层）**

  * 提取事件事实
  * 不变

* **Module B：Group Planner（结构层）**

  * 只生成群体骨架
  * 不再生成人设字段

* **Module C：Persona Writer（表达层）**

  * 基于 group skeleton 生成 persona 相关字段
  * 支持逐 group 并发执行

* **Module D：Rules Engine / Assembler（收口层）**

  * 合并 skeleton + persona
  * 完成规则收口并输出 `Phase1Output`

* **Module E：Orchestrator（编排层）**

  * 负责串联：

    * extractor
    * planner
    * persona_writer
    * rules_engine
    * validator

# 📦 字段职责迁移（新增关键模块）

### 从 Group Planner 移出（改由 Persona Writer 处理）

* 字段：

  * `persona_name`
  * `age_range`
  * `occupation`
  * `personality`
  * `motivation`
  * `typical_phrases`
  * `communication_style`
* 原因：

  * 这些字段属于表达层，不属于结构层
  * 与群体骨架字段解耦后，结构更稳、表达更灵活
  * 便于未来切换轻量 persona 模式或模板派生模式

---

### 保留在 Group Planner

* 字段：

  * `group_name`
  * `related_event_entity`
  * `description`（可保留为简版骨架描述）
  * `I`
  * `susceptibility`
  * `raw_weight`（若 v1.1.15 已采用）
* 原因：

  * 这些字段属于群体结构骨架

---

### 延后生成（未来阶段处理）

* 字段：

  * 个体级 agent 派生 persona
  * speaker-level 风格扰动
  * 大规模实例化后的局部语言模板
* 原因：

  * 这些属于后续规模化阶段，不在本轮实现范围内
