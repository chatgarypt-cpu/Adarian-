## 🎯 本次迭代目标

### 问题描述

* 当前存在的问题：

  * `phase1_entity_extraction.py` 职责过载，同时承担：

    * 事件事实提取
    * event_entities 抽取
    * relations 提取
    * opinion_spreaders 生成
    * I / P / susceptibility 分配
    * percentage 生成与分布控制
    * persona / personality / phrases 等表达层内容生成
    * 结构校验与部分修补
  * 单体 Prompt 过长，字段之间互相干扰
  * 当前 Phase 1 缺乏显式中间层，难以维护、难以扩展、难以继续收规则
* 影响范围：

  * Phase 1 可维护性
  * 后续 Rules Engine 引入
  * 后续 Persona Writer 独立
  * 后续并发执行能力
* 是否为结构性问题（是/否）：**是**

---

### 解决目标

* 本次希望达成的效果：

  * 将当前单体 Phase 1 拆为：

    * Entity Extractor
    * Group Planner
    * Orchestrator
  * 保持系统端到端仍可运行
  * 保持对外输出契约兼容
  * 为 v1.1.15 的规则收口提供清晰挂载点
* 是否允许 breaking change：**否**
* 本次是否涉及架构调整（是/否）：**是**

---

# 🧠 架构变更说明（新增关键模块）

### 当前结构问题

* 当前 `phase1_entity_extraction.py` 是“大一统单体”
* 同一个文件同时承担：

  * 事实层
  * 结构层
  * 部分表达层
  * 部分收口层
* 当前 Phase 1 内部没有显式模块边界
* 不利于逐步迁移到目标四层架构

---

### 目标结构（本次之后）

列出模块划分：

* **Module A：Entity Extractor（事实层）**

  * 负责从 seed 中提取：

    * `event_summary`
    * `event_scale`
    * `event_controversy`
    * `event_type`
    * `event_entities`
    * `relations`
  * 不负责生成 opinion_spreaders

* **Module B：Group Planner（结构层）**

  * 负责基于事实层结果生成：

    * `opinion_spreaders`
  * 本轮允许暂时保留现有字段生成逻辑，以保证兼容

* **Module C：Phase1 Orchestrator（编排层）**

  * 负责串联：

    * extractor
    * planner
    * validator / 现有后处理
  * 对外仍输出现有 `Phase1Output`
