## 🔧 详细修改指令

### 任务 1：构建核心基础设施

**功能**：搭建 schemas、config、llm_client 三个核心模块

**模块说明**：
- `schemas.py`: 定义 Phase1-4 所有数据结构的 Pydantic 模型
- `config.py`: 集中管理 API 配置、路径、参数
- `llm_client.py`: 统一封装 LLM 调用，支持 DeepSeek/Zhipu/Qwen

**技术要求**：
- 所有 LLM 输出必须经过 Pydantic 校验
- 支持自动重试（最多 3 次）
- 兼容多种 provider 的 OpenAI SDK 格式

---

### 任务 2：实现 Phase 1 - 动态人群生成

**功能**：从种子文本提取人群原型，生成 Agent 画像

**Prompt 要点**：
- 识别冲突轴和利益相关方
- 输出 3-8 个 archetypes
- 每个 archetype 包含 stance_score、susceptibility、estimated_percentage
- 占比之和必须等于 100

**技术要求**：
- 收缩算法将人群映射为 5-15 个 Agent
- 每个 archetype 的第一个 Agent 标记为 core，其余为 periphery

---

### 任务 3：实现 Phase 2 - 社交拓扑构建

**功能**：基于 Agent 画像构建社交网络

**拓扑规则**：
- Core 节点：每个 archetype 中 susceptibility 最低的 Agent
- Periphery 节点：单向关注至少 1 个 core
- 使用 NetworkX DiGraph

---

### 任务 4：实现 Phase 3 - 多轮涌现推演

**功能**：Agent 在社交网络中多轮交互，观察情绪涌现

**模拟逻辑**：
- 每轮每个 Agent 读取关注者的发言
- 根据 susceptibility 和接收到的信息更新立场
- 计算 global_metrics（mean_stance、std_stance、polarization_index）
- 检测收敛（极化指数变化 < 0.05）停止

**关键输出**：x(t) 序列，用于后续 AD/SEIR 模块

---

### 任务 5：实现 Phase 4 - 宏观洞察生成

**功能**：基于模拟结果生成舆情报告

**报告结构**：
1. 事件概述
2. 利益相关方图谱
3. 情绪演化轨迹表
4. 拐点分析
5. 风险评估

**风险等级**：low / medium / high / critical

---

### 任务 6：串联四阶段 - main.py

**功能**：一键运行完整流程

**执行顺序**：
1. Phase 1: 动态人群生成
2. Phase 2: 社交拓扑构建
3. Phase 3: 多轮涌现推演
4. Phase 4: 宏观洞察生成
