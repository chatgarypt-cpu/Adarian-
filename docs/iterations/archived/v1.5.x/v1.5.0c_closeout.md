### 2. Goal & Boundary

**做什么：**

1. **历史任务 API** — `GET /api/history` 查询 SQLite `batches` 表返回按日期倒序列表，含 seed 摘要、模型列表、风险概要
2. **系统设置 API** — `GET/PUT /api/settings` 通过 `serve/db.py` 读写 SQLite `settings` 表（key-value），向用户暴露 JSON 形状
3. **前端接入** — 历史任务页（列表 + 筛选 + 复用入口）+ 系统设置页（表单）
4. **入口整合** — `adarian.sh serve` → `python -m adarian serve`（Flask）；`start.command` 同步更新
5. **E2E 验收 8 场景** — 编写 `scripts/smoke_api.sh`（curl 链）和 `scripts/smoke_e2e.sh`（Playwright）
6. **清理** — 全仓库搜索 `_legacy_serve` 引用确认无残留，通过 ≥3 次 `python -m adarian serve` 干净启动后，`git rm src/adarian/_legacy_serve.py`
7. **版本标记与回滚保障** — 每节点单独 git commit + tag（`v1.5.0a-nodeN`、`v1.5.0b-nodeN`、`v1.5.0c-nodeN`）；新增 `make rebuild` 规则：`rm -rf frontend/dist && npm run build && python -m adarian serve`
8. **验收 8 场景**（S1-S8）全部通过：
   - S1: 1 模型正常推演 → 8 步全绿
   - S2: 幂等重复提交同一 batch_id
   - S3: 2 模型中 1 失败 → 混合结论显示
   - S4: 零模型 → 400
   - S5: 非法 JSON → 400
   - S6: 未知 batch_id → 404
   - S7: 空 outputs/runs/ → history 返回 []
   - S8: 完整链路 seed → run → review → report → history 出现条目

**不做什么：**
- 不改 Phase 1-4 管线代码
- 不改 `batch.py`（除非紧急 bug）
- 不改 `run.py` / `inspect.py` 的 CLI 行为
- 不做 SSE 实时推送（留 v1.5.1）
- 不做在线报告编辑（留 v1.5.1）
