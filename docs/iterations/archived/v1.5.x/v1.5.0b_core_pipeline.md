### 2. Goal & Boundary

**做什么：**

1. **推演配置 API** — config CRUD（平行轮数、模拟步数、输出批次名、推演重点标签）
2. **模型调度 API** — 健康检测结果缓存，选择/取消选择
3. **run API** — `POST /api/run` 真实启动 batch 推演（调 `batch.py`），写入 `serve/db.py` 的 batches + worlds 表；返回 batch_id；`GET /api/run/<id>/status` 从 SQLite 读取每个 world 状态
4. **运行监控** — 前端每 2 秒轮询状态，展示每个 world 的模型名、阶段、耗时
5. **结果审查 API** — `GET /api/review/<batch_id>` 聚合跨 world 的 risk_verdict + risk_type_classification + 对比表格
6. **报告生成 API** — `POST /api/report` 调用 Phase 4 报告管线
7. **World 级重试 + 取消** — 在 `batch.py` 开白名单口子，新增 `rerun_world()` 函数和 `WorldState.proc_handle`；`POST /api/run/<batch_id>/<world_id>/retry` + `POST /api/run/<batch_id>/abort`（world 粒级）
8. **Batch.py 白名单修改** — 仅新增 `rerun_world()` 和 `WorldState.proc_handle` 字段，不修改已有函数体
9. **清除 §12.3 错误声明** — "world 间无数据依赖"改为"重试 world 会重新生成 Phase 1-2 共享数据，影响已成功 world 的审查视图"
10. **Vue 页面接入 API** — 02~06 页从静态原型改为真实数据

**不做什么：**
- 不改 `phase*/`、`analysis/`、`parser.py`、`llm_client.py`、`schemas/`
- 不改 `config.py` 的路径配置
- 不做历史任务页面（v1.5.0c）
- 不做系统设置页面（v1.5.0c）
- 不做 SSE 实时推送（优先轮询）
- 不改 v1.5.0a 已交付的 seed / models API 的响应结构

old_names = {n.name for n in ast.walk(old_tree) if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef))}
new_names = {n.name for n in ast.walk(new_tree) if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef))}

def fn_hash(tree, name):
    for n in ast.walk(tree):
