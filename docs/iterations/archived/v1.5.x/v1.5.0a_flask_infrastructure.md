### 2. Goal & Boundary

**做什么：**

1. **文件冲突修复** — `git mv serve.py _legacy_serve.py`；新建 `serve/__init__.py`；更新 `__main__.py` 导入
2. **Flask 骨架** — app factory + Blueprint + state.py（`_SESSIONS + _POOL + _ACTIVE_BATCHES`）+ ThreadPoolExecutor
3. **轻量 SQLite 数据库** — `outputs/.adarian.db`，三张表：batches（含 idempotency_key）、worlds、settings。替代 JSON 文件索引和纯扫描方案。
4. **seed + models API** — 事件录入 + 模型列表 + 健康检测
5. **Vue 工程** — npm init + vite ^5.4.0 + vue ^3.4.0 + vue-router + 8 步导航（纯静态原型，不调 API）；钉死版本 `frontend/.nvmrc` 写 `20`；提交 `package-lock.json`
6. **共享契约** — `serve/schemas.py`（Pydantic 信封）+ `api/types.ts` + `api_contract.md`
7. **APR 端点** — `POST /api/run/<batch_id>/abort` + 进程组 kill（`preexec_fn=os.setsid`）
8. **SAP catch-all** — `static.py` 注册非 `/api/*` GET → `index.html`
9. **测试** — pytest conftest + api_basics + idempotency + concurrency

**不做什么：**
- 不改 batch.py、run.py、config.py、phase1-4、analysis、parser、schemas、llm_client
- 不做推演启动（`POST /api/run` 返回模拟 batch_id，不真跑）
- 不做跨域 CORS（前端走 Vite 代理到 Flask）
- Vue 交付策略：开发模式用 Vite dev server（端口 5173）代理 `/api/*` 到 Flask（端口 9788）；生产模式由 Flask `static.py` 的 `send_from_directory('frontend/dist')` + catch-all 路由服务。v1.5.0a 只做开发模式，生产模式在 v1.5.0c 入口整合时验证。

PYTHONPATH=src .venv/bin/python -c "
import json
from adarian.serve import create_app
app = create_app()
client = app.test_client()
# ping
r = client.get('/api/ping')
assert r.status_code == 200
data = json.loads(r.data)
assert data['status'] == 'ok'
print('PING OK')
# ping 版本字段
assert 'version' in data
print('VERSION FIELD OK')
# seed
r = client.post('/api/seed', json={'seed_text': 'test'})
assert r.status_code == 200
print('SEED OK')
# models
r = client.get('/api/models')
assert r.status_code == 200
data = json.loads(r.data)
assert len(data) > 0
print('MODELS OK')
# idempotency: 同 key 同 result
r1 = client.post('/api/run', json={'seed_text': 't', 'models': ['m1']})
r2 = client.post('/api/run', json={'seed_text': 't', 'models': ['m1']})
assert json.loads(r1.data)['batch_id'] == json.loads(r2.data)['batch_id']
print('IDEMPOTENCY OK')
# concurrency cap
from adarian.serve.state import _ACTIVE_BATCHES
for i in range(3):
    _ACTIVE_BATCHES[f'dummy_{i}'] = {'status': 'running'}
r = client.post('/api/run', json={'seed_text': 'o', 'models': ['m2']})
assert r.status_code == 429
print('CONCURRENCY CAP OK')
print('ALL SMOKE CHECKS PASSED')
