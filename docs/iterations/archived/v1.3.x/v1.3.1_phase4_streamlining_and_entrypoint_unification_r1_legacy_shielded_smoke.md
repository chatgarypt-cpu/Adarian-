- 执行：Claude Code workflow / DAG

workflow_dag。原因：涉及 legacy 归档、clean source 清理、入口替换、tests/tools import 迁移、runtime 验证，横跨多个责任面，不适合 Codex 单节点一口气搬迁。

## 3.2 决策理由

v1.3.1 原 draft 方向正确，但 Pre-Execution Plan Review 给出 `revise_and_resubmit`，指出 5 个 hard blocker：tests import 未覆盖、unowned internal functions、`save_markdown_report` 与 `generate_markdown_report` 隐藏耦合、`report_narrative.py` 签名与 legacy caller 矛盾、缺运行时 no-legacy-compute 验证。

本 R1 修订的目标是把这些 blocker 直接写入执行合同，使 Claude Code 不再靠猜测处理 import 副作用、函数归属、测试迁移和 runtime 验证。

# 4. Goal & Boundary

## 4.1 本轮主目标

```text
将 Phase4 收束为 simulation_dataset 的纯消费端；
将旧入口与旧内联计算归档至 legacy；
统一产品主入口为 main.py 新路径；
保留 bypass 对比为 dev diagnostic 工具；
通过 runtime 证据证明 main.py 产品流程不再调用旧 Phase4 计算函数。
```

## 4.2 本轮解决的问题

1. `main.py` / `main_new.py` 双入口并存。
2. `src/phase4/report_agent.py` 同时承载 consumer 与 legacy analytics。
3. `src.phase4.__all__` 暴露旧计算函数。
4. 旧 tests / tools 仍 import 即将迁出的符号。
5. `save_markdown_report()` 与 `generate_markdown_report()` 存在 fallback 耦合。
6. `_llm_generated_markdown` 全局变量在新架构下成为分脑状态。
7. `parse_llm_report_response()` / `_build_code_owned_report_contract_block()` 仍可能保留 dataset=None 或旧路径分支。
8. bypass 对比仍可能被误认为产品流程的一部分。

## 4.3 本轮不解决的问题

1. 不做 20 类政府治理风险 taxonomy 技术转译。
2. 不实现 risk_type_classifier R0。
3. 不实现 governance_recommendations 结构化输出。
4. 不做 Phase3 模块间耦合治理。
5. 不拆 `RiskAnalyzer`。
6. 不拆 `report_normalizer.py`。
7. 不重写 prompt 语义。
8. 不改 `Phase4Output` schema 语义。
9. 不改 Phase1 / Phase2 / Phase3 tick simulation。
10. 不新增外部检索 / RAG / MCP。

## 4.4 禁止变化

```text
1. 禁止在 src.phase4 新代码中 import legacy。
2. 禁止在 main.py 产品主流程中 import legacy。
3. 禁止在清理后的 src/phase4/report_agent.py 中保留任何已移走的旧计算函数。
4. 禁止保留 save_markdown_report -> generate_markdown_report fallback。
5. 禁止保留 _llm_generated_markdown 全局变量。
6. 禁止 parse_llm_report_response 保留 dataset=None 旧计算分支。
7. 禁止 _build_code_owned_report_contract_block 保留非 dataset 分支。
8. 禁止修改 report_prompts.py 的 prompt 文本语义。
```

```text

                                                        |
                                                        v
```


## 5.3 Phase4 pure consumer 职责

Phase4 可以做：

```text
1. 接收 simulation_dataset。
2. 将 dataset 映射为 Phase4Output。
3. 构建基于 dataset 的 prompt contract block。
4. 调用 LLM 生成叙事 markdown。
5. 保存 final_report.json / final_report.md。
6. 做格式化、路径对齐、metadata header、normalizer 调度。
```

Phase4 不可以做：

```text

2. 重新计算 inflection_points。
3. 重新计算 agent_stance_matrix。
4. 重新判断 audience_mode。
5. 重新 classify risk_types。
6. 从旧 tick_logs 推导任何已经在 simulation_dataset 中存在的分析字段。
```

```python
import subprocess

LEGACY_NAMES = [
    "assess_risk",
    "identify_inflection_points",
    "select_primary_risk_types",
    "determine_audience_mode",

def test_no_legacy_compute_at_runtime():
```

## 11.5 Legacy-Shielded E2E Smoke Test（归档屏蔽烟雾测试）

参考实现：

```python
"""tests/test_phase4_legacy_shielded_e2e.py
E2E smoke: archived Phase4 legacy interfaces are blocked; product main path must still pass.
"""
import subprocess


def test_legacy_phase4_archived_interfaces_are_not_required_by_product_e2e():
    wrapper = r'''
import importlib.abc
import runpy
import sys

for name in list(sys.modules):
    if name == "legacy.main_legacy" or name.startswith("legacy.phase4"):
        del sys.modules[name]

class BlockLegacyPhase4(importlib.abc.MetaPathFinder):
    def find_spec(self, fullname, path=None, target=None):
        if fullname == "legacy.main_legacy" or fullname.startswith("legacy.phase4"):
            raise ImportError(f"ARCHIVED_PHASE4_BLOCKED_DURING_E2E: {fullname}")
        return None

sys.meta_path.insert(0, BlockLegacyPhase4())
sys.argv = ["main.py", "seeds/test8.txt"]
runpy.run_path("main.py", run_name="__main__")
'''
    result = subprocess.run(
        [".venv/bin/python", "-c", wrapper],
        capture_output=True,
        text=True,
        timeout=240,
    )
    assert result.returncode == 0, (
        "Product E2E required archived Phase4 legacy interfaces or failed under shield.\n"
        f"STDOUT tail:\n{result.stdout[-2000:]}\n"
        f"STDERR tail:\n{result.stderr[-2000:]}"
    )
```
