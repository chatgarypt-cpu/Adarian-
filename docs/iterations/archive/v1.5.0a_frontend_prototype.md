## 第 1 层：Owner Brief

**1. 这轮干嘛？**

把产品同学的原型 HTML 移植为完整的 Vue 3 SPA：8 个页面、全部组件库、Pinia store 定义、所有页面状态（loading/empty/error/populated）用 mock 数据展示。

后端只做 Flask `/api/ping` 验证前后端联通。

**2. 为什么现在做？**

原型 HTML 定义了完整的前端规格（组件、状态、数据流），但先造骨架再造前端等于后端猜前端需求。本轮前端先行：8 页全部实现完毕，后端按需服务。

### 2. Goal & Boundary

**做什么：**

1. **Vue 工程搭建** — Vite 5 + Vue 3 + Pinia + vue-router + TypeScript；版本钉死（`^5.4.0` / `^3.4.0`）；提交 `package-lock.json`；
2. **设计系统** — 从原型 HTML 提取 CSS 变量、布局、颜色，实现全局样式 `frontend/src/style.css`
3. **8 个组件** — Panel / Card / Chip / StepLine / Mini / WorldCard / LogBox / Badge，每个都是独立 Vue 组件，props 定义完整
4. **8 个页面全部实现** — 每个页面的所有 UI 状态（loading / empty / error / populated）用 mock 数据驱动
5. **Pinia store** — 定义 seed / run / history / settings 四个 store，覆盖 8 页所有跨页状态
6. **路由 + 导航** — 8 步侧边栏切换（原型 exact），刷新后回到当前步骤（localStorage）
7. **API 契约** — `frontend/src/api/types.ts` 定义所有请求/响应接口；`api/mock.ts` 提供 mock 数据
8. **Flask `/api/ping`** — app factory + ping endpoint，仅验证前后端联通
9. **前端测试** — vitest 组件测试（Panel / Card / Chip / StepLine）；8 页路由测试

**不做什么：**
- 不实现任何真实业务 API（seed / models / run / review / report / history / settings）
- 不改后端生产代码（phase*/ batch.py / run.py / config.py / parser.py）
- 不使用 SQLite（v1.5.0b）
- 不做 CORS（前端 Vite proxy 到 Flask）

**设计参考：** `docs/adarian_frontend_spec.md`（从原型提取的完整规格）
