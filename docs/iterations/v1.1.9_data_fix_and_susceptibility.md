## 三、详细修改指令

### 3.1 Phase 4 报告数据源修复

**目标**：最终报告中的 stance 变化数字必须从 tick_log 真实计算。

**当前问题**：
- Phase 4 的 `build_full_report_context` 函数从 `entities_and_relations.json` 的 archetype 读初始值
- tick_log 里记录了每轮的 stance 值，但未被利用

**修改点**：`src/phase4_report_agent.py`

```python
def build_full_report_context(tick_logs: List[TickLog],
                             phase1_output: EntityExtractionOutput) -> dict:
    """构建报告上下文"""

    # ===== 修复：读取真实最终立场 =====
    final_stances = {}
    initial_stances = {}

    # 从 tick_log 最后一步读取最终立场
    last_tick = tick_logs[-1]
    for entry in last_tick.entries:
        final_stances[entry.agent_id] = entry.current_stance

    # 从 tick_log 第一步读取初始立场（而非 archetype）
    first_tick = tick_logs[0]
    for entry in first_tick.entries:
        initial_stances[entry.agent_id] = entry.current_stance

    # 计算真实 stance 变化
    stance_changes = {}
    for agent_id in final_stances:
        if agent_id in initial_stances:
            stance_changes[agent_id] = round(
                final_stances[agent_id] - initial_stances[agent_id], 2
            )

    return {
        # ... 其他字段 ...
        "initial_stances": initial_stances,
        "final_stances": final_stances,
        "stance_changes": stance_changes,
    }
```

**验证方式**：运行 `python main.py seeds/test2.txt`，对比 final_report.md 中的 stance 变化数字与 tick_logs 最后一轮的数字。

### 3.2 susceptibility 简单接入

**目标**：让 susceptibility 字段真实影响 stance 变化幅度上限。

**设计思路**：
- 当前 confirmation_bias_level 控制变化幅度上限（strong=±0.3, weak=±0.5, none=±0.8）
- susceptibility 高 → agent 更易被影响 → 应允许更大变化幅度
- 采用乘法调制：`变化上限 = 基础上限 × (1 + susceptibility × 系数)`

**config.py 新增参数**：

```python
# susceptibility 调制系数
# susceptibility 高（>0.7）的 agent 变化幅度可增加 50%
SUSCEPTIBILITY_MODULATION_FACTOR = 0.5
```

**phase3_tick_simulation.py 修改**：

```python
def compute_stance_change_with_susceptibility(
    agent: GraphNode,
    previous_stance: float,
    proposed_stance: float,
    confirmation_bias_level: str,
    susceptibility: float
) -> Tuple[float, str]:
    """
    计算新的 stance 值，接入 susceptibility 调制变化幅度
    返回: (new_stance, reason)
    """

    # 1. 计算基础变化上限
    base_delta_map = {
        "strong": 0.3,
        "weak": 0.5,
        "none": 0.8
    }
    base_delta = base_delta_map.get(confirmation_bias_level, 0.3)

    # 2. susceptibility 调制：高 susceptibility → 更大变化幅度
    # modulation = 1 + SUSCEPTIBILITY_MODULATION_FACTOR × (susceptibility - 0.5)
    # 即 susceptibility=1.0 时，modulation = 1.25
    #     susceptibility=0.0 时，modulation = 0.75
    susceptibility_modulation = 1 + SUSCEPTIBILITY_MODULATION_FACTOR * (susceptibility - 0.5)
    effective_delta = base_delta * susceptibility_modulation

    # 3. 限制变化幅度
    delta = proposed_stance - previous_stance
    if abs(delta) <= effective_delta:
        # LLM 提议在范围内，直接通过
        return proposed_stance, "within_effective_delta"
    else:
        # 截断到边界
        bounded_stance = previous_stance + math.copysign(effective_delta, delta)
        bounded_stance = round(clamp(bounded_stance, 1.0, 10.0), 2)
        return bounded_stance, "bounded_by_susceptibility"
```
