## 4. Implementation Summary

### 4.1 Markdown Output Guard

在 `src/phase4/report_agent.py` 中新增：

```text
_replace_reality_claims_about_inflection(markdown: str) -> str
```

该函数将以下现实化表达改写为模拟推演口径：

```text
现实舆情已经出现拐点
现实舆情出现拐点
全网舆情发生转折
全网舆情已经转向
公众态度已经改变
公众态度发生转折
舆情已经发生转折
传播拐点已经出现
真实舆情拐点
现实传播拐点
```

改写口径：

```text
本轮模拟显示出值得关注的模拟关键变化点。
该节点仅代表本轮模拟设定下的演化特征，不等同于现实舆情传播中的真实转折。
```

接入位置：

```text
_normalize_saved_markdown()
  _replace_placeholder_residue()
  _replace_reality_claims_about_inflection()
  _replace_quote_fabrication_patterns()
```

### 4.2 Duplicate Prefix Guard

`_replace_report_metric_terms()` 改为正则替换，避免：

```text
模拟模拟极化指数
模拟模拟关键变化点
模拟模拟立场均值
```

### 4.3 Whitebox Alignment

在现有 `src/whitebox/report_completeness.py` 的 detail result 中增加：

```text
inflection_points_json_count: int
inflection_points_markdown_claim: empty_claim / non_empty_claim / no_claim / reality_claim_detected
inflection_points_consistency: match / mismatch / not_applicable
empty_inflection_text_present: bool
reality_inflection_claim_detected: bool
inflection_consistency_issue: string
```

`src/whitebox/report_observer.py` 仅尝试读取同目录 `final_report.json`，读取失败时 graceful degrade，不 hard fail。

保持不变：

```text
1. whitebox_summary.json 顶层 contract 不变。
2. 不新增 whitebox artifact 文件。
3. 不让 whitebox 改写 final_report.md。
4. 不让 whitebox 参与报告生成。
```

### 4.4 Concurrent Run Directory Hotfix

`main.py::build_run_paths()` 将输出目录从单层秒级时间戳：

```text
{seed_stem}_YYYYmmdd_HHMMSS
```

调整为：

```text
outputs/runs/{seed_stem}_YYYYmmdd_HHMMSS/run_{microseconds}_{pid}/
```

同一秒触发的并发运行共享 `{seed_stem}_YYYYmmdd_HHMMSS` batch 目录；每个进程写入独立 `run_{microseconds}_{pid}` 子目录。该修复保留子目录 `exist_ok=False`，避免覆盖已有 run_dir。
