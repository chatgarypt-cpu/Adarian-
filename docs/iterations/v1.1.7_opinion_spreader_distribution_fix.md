## 🎯 本次修复目标

### 问题 1：强制立场分布导致不真实群体
**现象**：
- 高烈度负面事件（如鼠头事件）强制生成"支持者"
- test3 中出现"校方支持者"（立场 2.5），不符合真实舆情
- test2 中出现"譚竹支持者"，胖猫事件不应有支持者

**解决方案**：
- LLM1 判断 `group_distribution_strategy`（normal / minimal_supporters / no_supporters）
- 根据"官方是否及时处置"和"是否认错"决定策略
- LLM2 根据策略生成群体（no_supporters 时不生成支持者）
- LLM3 校验群体分布合理性

### 问题 2：负面事件立场变化不符合现实
**现象**：
- test3 中"校方支持者"立场上升（2.2 → 3.7）
- 真实舆情中，官方认错后支持者应该减少或立场下降

**解决方案**：
- 根源上解决问题 1（不生成不真实的支持者）
- 如果生成了极少数支持者，Phase 3 中增加"舆论压力"机制

### 任务 2：修改 phase1_entity_extraction.py - LLM1 判断策略

**功能**：LLM1 分析事件，判断群体分布策略

**修改位置**：`src/phase1_entity_extraction.py` 中的 `LLM1_SYSTEM_PROMPT`

**输入**：
- 种子材料文本

**输出**：
```json
{
  "event_temperature": 0.9,
  "event_intensity": 0.85,
  "event_type": "食品安全危机",
  "has_official_response": true,
  "official_admits_fault": true,
  "group_distribution_strategy": "no_supporters"
}
```

**LLM Prompt 要点**：

**【群体分布策略判断规则】**

1. **判断官方回应情况**：
   - `has_official_response`：种子材料中是否有官方/机构的回应？
   - `official_admits_fault`：官方是否承认错误/道歉？

2. **策略判断逻辑**：

| 条件 | 策略 | 说明 |
|------|------|------|
| 高烈度(≥0.8) + 负面事件 + 官方延迟回应/拒不承认 | `no_supporters` | 完全不生成支持者 |
| 高烈度(≥0.8) + 负面事件 + 官方延迟回应但认错 | `minimal_supporters` | 极少数支持者（5-10%） |
| 高烈度(≥0.8) + 负面事件 + 官方及时回应且认错 | `normal` | 正常生成（20-30%） |
| 其他情况 | `normal` | 正常生成 |

3. **判断标准**：
   - **及时回应**：事件发生后 24 小时内回应
   - **延迟回应**：事件发酵后才回应，或被舆论压力逼迫回应
   - **拒不承认**：官方否认/甩锅/试图掩盖

**技术要求**：
- `group_distribution_strategy` 必须为 "normal" / "minimal_supporters" / "no_supporters" 之一
- `has_official_response` 和 `official_admits_fault` 必须为 bool 类型

### 任务 3：修改 phase1_entity_extraction.py - LLM2 按策略生成群体

**功能**：LLM2 根据 `group_distribution_strategy` 调整群体生成规则

**修改位置**：`src/phase1_entity_extraction.py` 中的 `LLM2_SYSTEM_PROMPT`

**输入**：
- LLM1 输出的事件参数（包含 `group_distribution_strategy`）
- 种子材料文本

**输出**：
```json
{
  "opinion_spreaders": [
    {
      "group_name": "食品安全关注者",
      "related_event_entity": "江西工業職業技術學院",
      "description": "关注食品安全问题的网友",
      "stance_score": 9.0,
      "susceptibility": 0.7,
      "confirmation_bias_level": "strong",
      "estimated_percentage": 40,
      "communication_style": "愤怒、质疑",
      "entity_category": "opinion_spreader"
    }
  ]
}
```

**LLM Prompt 要点**：

**【群体生成规则】**

**如果 `group_distribution_strategy == "no_supporters"`**：

| 群体类型 | 可生成 | 说明 |
|---------|--------|------|
| 批评者 | ✅ | 对官方/机构持批评态度 |
| 中立观察者 | ✅ | 保持中立，客观分析 |
| 调侃者/段子手 | ✅ | 以幽默方式评论 |
| 受害者支持者 | ✅ | 支持受害者，而非支持官方 |
| 法律关注者 | ✅ | 关注法律程序 |
| 专家/媒体评论员 | ✅ | 客观分析事件 |
| 官方支持者 | ❌ | **不生成** |
| 校方支持者 | ❌ | **不生成** |
| XX品牌支持者 | ❌ | **不生成** |

**如果 `group_distribution_strategy == "minimal_supporters"`**：
- 可生成 1-2 个"理性支持者"群体
- 比例不超过 10%
- 群体名称：理性观察者、法律支持者、官方认可者

**如果 `group_distribution_strategy == "normal"`**：
- 正常生成，支持者比例 20-30%

**技术要求**：
- 群体总数不超过 15 个
- 立场分布符合策略要求

### 任务 4：修改 phase1_entity_extraction.py - LLM3 校验群体分布

**功能**：LLM3 校验群体分布是否符合策略

**修改位置**：`src/phase1_entity_extraction.py` 中的 `LLM3_SYSTEM_PROMPT`

**输入**：
- LLM2 输出的群体数据
- LLM1 输出的 `group_distribution_strategy`

**输出**：
- 校验通过：`{"valid": true}`
- 校验失败：`{"valid": false, "errors": ["错误描述"]}`

**LLM Prompt 要点**：

**【群体分布校验规则】**

1. **如果 `group_distribution_strategy == "no_supporters"`**：
   - 检查 `opinion_spreaders` 中是否存在"支持者"、"官方认可"、"校方支持"、"品牌支持"等群体
   - 检查群体名称中是否包含"支持"、"粉丝"、"拥护"等关键词
   - 如果存在，报错："策略为 no_supporters，不应生成支持者群体"

2. **如果 `group_distribution_strategy == "minimal_supporters"`**：
   - 统计支持者群体的 `estimated_percentage` 总和
   - 如果超过 15%，报错："策略为 minimal_supporters，支持者比例不应超过 15%"

3. **如果 `group_distribution_strategy == "normal"`**：
   - 正常校验（保持 v1.1.5 的校验规则）

**技术要求**：
- 校验失败时，LLM2 需要重新生成

### 任务 5：修改 phase3_tick_simulation.py - 增加舆论压力机制

**功能**：如果生成了支持者，在批评主导的舆论中立场应下降

**修改位置**：`src/phase3_tick_simulation.py` 中的 `generate_opinion_spreader_post()` 方法

**输入**：
- 当前 agent 的立场
- 全局平均立场（mean_stance）

**输出**：
- 调整后的立场变化

**输出格式**：
```python
# 如果全局平均立场 < 4.0（批评主导）
# 且该 agent 是支持者（stance >= 7.0）
# 则施加"舆论压力"，立场略微下降
```

**LLM Prompt 要点**：
- 在 `AGENT_POST_SYSTEM_PROMPT` 中增加：
  ```
  【舆论压力提示】（v1.1.7）
  当前舆论整体倾向：{overall_sentiment}
  - 如果舆论整体批评，而你是支持者，你可能感受到孤立和压力
  - 如果舆论整体支持，而你是批评者，你可能更加坚定
  ```

**技术要求**：
- 舆论压力不应过强，立场变化仍受确认偏差约束
- 只在 `group_distribution_strategy == "minimal_supporters"` 时启用
