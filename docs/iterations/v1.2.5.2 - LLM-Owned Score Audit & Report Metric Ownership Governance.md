### 决策理由

v1.2.5.2 起初是 S-Level 小治理版本，目标是审计 Phase 1-4 中 score / metric / categorical level 的所有权，确认哪些指标由 LLM 生成，哪些指标由代码计算，哪些指标由 schema property 推导。
