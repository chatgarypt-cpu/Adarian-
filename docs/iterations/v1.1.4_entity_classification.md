## 🎯 本次修复目标

### 核心目标
在 Phase 1 内部建立 LLM1/2/3 协作架构，实现**实体分类**（事件实体 vs 意见传播实体），并通过迭代校验确保输出质量。

### 两种实体类型

#### 事件实体（Event Entity）
- 直接参与话题讨论
- 作为第一批发言者（Tick 0）
- 从种子文本中提取，如：李佳琦、花西子品牌方
- 作为社交网络中的 Core 节点，事件实体之间互相连接

#### 意见传播实体（Opinion Spreader）
- 不直接参与事件，但会传播意见
- 基于 event_temperature 和 event_intensity 生成
- 类型包括：粉丝、支持者、专家、批评者
- 生成逻辑：
  - **事件温度（event_temperature）** → 决定批评者比例
  - **事件烈度（event_intensity）** → 决定是否出现多样化传播者（高烈度→多样，低烈度→少量）
- 必须关注事件实体才能发言

### LLM1/2/3 协作流程

```
种子文本
   ↓
LLM1：分析种子材料 → event_temperature + event_intensity
   ↓
LLM2：提取事件实体 + 生成意见传播者
   ↓
LLM3：格式校验（JSON? 两列实体? 总量≤15?）
   ↓ 失败→反馈给LLM2重新生成
   ↓ 成功
输出：event_entities + opinion_spreaders
```

**迭代校验循环逻辑**：
```python
MAX_RETRIES = 3

def extract_entities_with_validation(seed_text: str) -> EntityExtractionOutput:
    """
    带迭代校验的实体提取

    流程：
    1. LLM1：设置 event_temperature + event_intensity
    2. LLM2：提取事件实体 + 生成意见传播者
    3. LLM3：校验格式
    4. 如果不通过，反馈错误给 LLM2，重新生成
    5. 最多重试 MAX_RETRIES 次
    """
    llm = get_llm_client()

    # Step 1: LLM1 设置参数
    temp_result = llm1_set_parameters(seed_text)
    event_temperature = temp_result["event_temperature"]
    event_intensity = temp_result["event_intensity"]

    # Step 2-4: LLM2 生成 + LLM3 校验（迭代）
    for attempt in range(MAX_RETRIES):
        # LLM2 生成
        raw_result = llm2_generate_entities(seed_text, event_temperature, event_intensity)

        # LLM3 校验
        validation = llm3_validate(raw_result)

        if validation["pass"]:
            return EntityExtractionOutput(**raw_result)

        # 不通过，反馈错误给 LLM2 重试
        error_feedback = validation["errors"]
        raw_result = llm2_retry(raw_result, error_feedback)

    # 达到最大重试次数，使用最后一次结果
    return EntityExtractionOutput(**raw_result)
```

### 任务 3：修改 `phase2_topology_builder.py` - 适配新实体类型

**功能**：基于新的实体分类构建社交拓扑

**Core-Periphery 映射规则**：
- **事件实体** → 全部作为 Core 节点
- **意见传播实体** → 全部作为 Periphery 节点

**边构建规则**：
```python
def build_topology(
    event_entities: List[Entity],
    opinion_spreaders: List[OpinionSpreader]
) -> Tuple[List[GraphNode], List[GraphEdge]]:
    """
    构建社交网络拓扑

    修改于：v1.1.4
    - 事件实体作为 Core
    - 意见传播实体作为 Periphery
    - 事件实体之间互相关注
    - Periphery 必须关注事件实体
    - Periphery 之间可选连接
    """
    nodes = []
    edges = []
    agent_id = 0

    # 1. 事件实体 → Core 节点
    event_entity_map = {}  # name -> node
    for entity in event_entities:
        node = GraphNode(
            id=agent_id,
            group_name=entity.name,
            archetype_index=-1,  # 事件实体用 -1 标记
            related_entity=entity.name,
            role=NodeRole.CORE,
            stance_score=5.0,  # 事件实体默认中立（后续可调整）
            susceptibility=0.0,
            confirmation_bias_level="none"
        )
        nodes.append(node)
        event_entity_map[entity.name] = node
        agent_id += 1

    # 2. 意见传播实体 → Periphery 节点
    for spreader in opinion_spreaders:
        node = GraphNode(
            id=agent_id,
            group_name=spreader.group_name,
            archetype_index=-2,  # 意见传播实体用 -2 标记
            related_entity=spreader.related_event_entity,
            role=NodeRole.PERIPHERY,
            stance_score=spreader.stance_score,
            susceptibility=spreader.susceptibility,
            confirmation_bias_level=spreader.confirmation_bias_level
        )
        nodes.append(node)
        agent_id += 1

    # 3. 事件实体之间互相关注（Core ↔ Core）
    event_nodes = [n for n in nodes if n.archetype_index == -1]
    for i, core_a in enumerate(event_nodes):
        for core_b in event_nodes[i+1:]:
            edges.append(GraphEdge(
                source=core_a.id,
                target=core_b.id,
                type=EdgeType.FOLLOWS_CORE_CROSS
            ))
            edges.append(GraphEdge(
                source=core_b.id,
                target=core_a.id,
                type=EdgeType.FOLLOWS_CORE_CROSS
            ))

    # 4. 意见传播实体必须关注关联的事件实体
    periphery_nodes = [n for n in nodes if n.archetype_index == -2]
    for periphery in periphery_nodes:
        # 找到关联的事件实体节点
        target_core = event_entity_map.get(periphery.related_entity)
        if target_core:
            edges.append(GraphEdge(
                source=periphery.id,
                target=target_core.id,
                type=EdgeType.FOLLOWS
            ))

    # 5. 意见传播实体之间可选连接（30% 概率）
    for i, peri_a in enumerate(periphery_nodes):
        for peri_b in periphery_nodes[i+1:]:
            if random.random() < 0.3:
                edges.append(GraphEdge(
                    source=peri_a.id,
                    target=peri_b.id,
                    type=EdgeType.FOLLOWS_CROSS_GROUP
                ))

    return nodes, edges
```

def run_tick_n(
    opinion_spreaders: List[GraphNode],
    event_entity_posts: List[TickEntry],  # Tick 0 的事件实体发言
    saw_posts: Dict[int, List[TickEntry]],  # agent_id -> 看到的发言
    ...
) -> List[TickEntry]:
    """
    Tick N：意见传播实体发言

    修改于：v1.1.4
    - 只有意见传播实体参与
    - 必须看到事件实体的发言
    """
    tick_entries = []

    for agent in opinion_spreaders:
        # 获取该 agent 看到的发言（必须包含事件实体发言）
        posts = saw_posts.get(agent.id, [])

        # 如果还没有看到事件实体发言，从 event_entity_posts 获取
        if not any(p.group_name in [e.name for e in event_entities] for p in posts):
            posts = event_entity_posts + posts

        prompt = build_opinion_spreader_prompt(
            agent=agent,
            saw_posts=posts,
            ...
        )

        response = llm_client.call(prompt)

        # 应用 stance 变化约束
        final_stance = apply_stance_constraint(...)

        entry = TickEntry(
            agent_id=agent.id,
            group_name=agent.group_name,
            saw_posts_from=[p.agent_id for p in posts],
            previous_stance=agent.stance_score,
            current_stance=final_stance,
            stance_delta=final_stance - agent.stance_score,
            comment=response["comment"],
            reasoning=response["reasoning"]
        )
        tick_entries.append(entry)

    return tick_entries
