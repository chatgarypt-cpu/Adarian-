# 7. Post-Execution Review Scope

Reviewer Team 只读验收重点：

```text
1. src.phase4 public API shape。
2. clean source 是否 import legacy。
3. main.py 是否唯一产品入口。
4. legacy 是否仅被 tests/tools/dev diagnostic 引用。
5. field provenance 是否来自 simulation_dataset。
6. runtime no-legacy-compute 是否真实跑过。
7. tests 是否被合理迁移，而不是删除绕过。
8. report_agent.py 是否仍有旧计算残留。
9. save_markdown_report 是否显式 markdown-only。
10. parse_llm_report_response / contract block 是否 dataset-only。
```

Reviewer Team 不做：

```text
1. 不要求实现 20 类风险 taxonomy。
2. 不要求 Phase3 module coupling review。
3. 不要求拆 RiskAnalyzer。
4. 不要求拆 report_normalizer。
5. 不替 Owner closeout。
```
