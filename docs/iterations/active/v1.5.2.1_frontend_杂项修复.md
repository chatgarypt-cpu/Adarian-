## 第 1 层：Owner Brief

**这轮干嘛？**

五个独立的小修复/补齐项，没有单一主题：

1. **06-report completed 后展示报告阅读器** — 前端不绑定 `.md`；后端提供结构化 report view-model，下载区展示多格式 artifacts。

- 不改 Phase、analysis、parser、llm_client、schemas。

## 第 2 层：Goals

### Goal 1 — 06-report completed 后展示报告阅读器

**现状**：completed 后只显示文件下载链接（`<a>` tags in `.file-list`）。

**目标**：completed 后自动拉取第一份正式报告的结构化正文数据，在前端展示可读报告阅读器。

重要判断：

- 不把“生成报告”前端体验限定为“fetch `.md` + Markdown parser 渲染”。
- 浏览器标准库没有 Markdown parser；为了前端体验和安全，本轮不新增 `marked` / `markdown-it` / `dompurify`。
- 后端已经有正式 `.md` 产物，前端体验应消费一个安全的 report view-model，而不是直接消费原始 Markdown HTML。
- `.md` 只是早期 MVP 的一个下载 artifact，不是长期前端契约。后续 PDF / DOCX / HTML / JSON 等格式应只扩展下载列表，不改变阅读器数据契约。
- 本轮使用 Python 标准库解析 Markdown 标题和段落为结构化 section 数据，前端用 Vue 模板渲染；下载 `.md` 仍保留。

**Owner**：Codex

**修改文件**：

```
修改:
  frontend/src/pages/06-report.vue    # 新增 reportView 状态 + 阅读器 UI
  frontend/src/api/types.ts           # 新增 ReportView/ReportSection 类型
  frontend/src/api/client.ts          # 新增 getReportView(jobId, fileId)

新增:
  src/adarian/report/view_model.py    # Python 标准库解析 Markdown -> sections

修改:
  src/adarian/serve/api/report.py     # 新增 GET /api/report/jobs/<job_id>/view/<file_id>
```

**验收**：
- [x] completed 后页面不只有下载链接，还展示完整报告阅读器
- [x] 正文以标题、章节、段落、列表等结构化区块展示
- [x] 多版本时展示第一个版本正文 + 版本切换 tab
- [x] 不阻塞其他操作（下载 artifacts 仍可用）
- [x] 不拉取 `appendix_b.json` / `audit_report.json` 作为正文
- [x] 前端不使用 `v-html` 渲染 LLM 原文
- [x] `GET /api/report/jobs/<job_id>/view/<file_id>` 只能读取 `files_json` 中的正式报告文件，不能读 appendix/audit 或任意路径
- [x] 阅读器不假设报告一定是 `.md`；若 artifact 不是可解析正文格式，显示“该格式仅下载，不支持预览”

**技术路径**：
1. 使用现有 `reportFiles = files.filter(file => file.appendix !== 'data')`，严禁直接取 `files[0]`。
2. completed 后默认选中 `reportFiles[0].id`。
3. 前端调用 `api.getReportView(jobId, fileId)`，而不是直接 fetch 文件 URL。
4. 后端从 `report_jobs.files_json` 中按 `file.id` 找正式报告 artifact：
   - `file.appendix === 'data'` 的 appendix/audit 不允许进入 view endpoint。
   - 使用现有 `_safe_job_file` 做路径防护。
   - 当前支持 `.md` 转 view-model；其他格式返回 `preview_supported=false` 和说明。
5. `view_model.py` 用 Python 标准库完成 `.md` 轻量解析：
   - `#` 标题作为 `title`
   - `##` 作为一级 section
   - `###` 作为 subsection
   - 普通段落 / `- ` 列表 / 数字列表作为 block
   - 表格可先作为 `preformatted` 或 `table_text` block，后续再升级
6. 前端阅读器用 Vue 原生模板渲染 `sections`，不使用 `v-html`。
7. 下载 artifacts 区独立展示所有正式报告格式；view 拉取失败或不支持预览时，只影响阅读器，不影响下载。

`ReportView` contract：

```ts
interface ReportViewBlock {
  type: 'paragraph' | 'list' | 'preformatted';
  text?: string;
  items?: string[];
}

interface ReportViewSection {
  heading: string;
  blocks: ReportViewBlock[];
  children?: ReportViewSection[];
}

interface ReportViewResponse {
  file_id: string;
  name: string;
  format: 'md' | 'pdf' | 'docx' | 'html' | 'json' | 'unknown';
  version: string;
  appendix: string;
  preview_supported: boolean;
  message?: string;
  title: string;
  sections: ReportViewSection[];
  raw_available: boolean;
}
```

`ReportFile` / artifact contract 补充：

```ts
interface ReportFile {
  id: string;
  name: string;
  url: string;
  version?: string;
  appendix?: string;
  format?: 'md' | 'pdf' | 'docx' | 'html' | 'json' | 'unknown';
  previewable?: boolean;
}
```

当前 runner 只生成 `.md`，但必须把 `format='md'` / `previewable=true` 写入正式报告 artifact；后续 PDF/DOCX 只新增 artifact，不改前端阅读器主契约。
