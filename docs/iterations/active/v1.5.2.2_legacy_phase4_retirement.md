# v1.5.2.2 — Legacy Phase 4 Runtime Retirement

> Hotfix after v1.5.2.1. 目标是减少 world 生成耗时：旧 `src/adarian/phase4/` 报告包移入归档目录，不再被默认 pipeline 执行。

## Owner Brief

`v1.5.2.1` 的目标是前端杂项和报告 view-model，没有触碰旧 inline report pipeline。代码现实是 `main.py` 在每个 world 生成 `simulation_dataset.json` 后仍继续调用旧 LLM 报告链路，导致 batch world 生成时间被报告生成占用。

新报告能力已经改为 `/api/report` 按需消费 completed worlds 的 `simulation_dataset.json`，旧 inline report 可以退役并归档。
