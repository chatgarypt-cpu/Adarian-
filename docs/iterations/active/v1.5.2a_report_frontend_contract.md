# v1.5.2a — 报告生成最薄真实链路

> 四层工作流。独立归档。
> 本轮不再做完整 fake 工作台；目标是先打通一条可验收的真实报告链路。
> 交付物：用户在 `06-report` 点一次生成，后端读取 completed worlds 的 `simulation_dataset.json`，生成 `appendix_b.json` 和一份 B 版无附录 Markdown 报告。

---

## 第 1 层：Owner Brief

**1. 这轮干嘛？**

把 `06-report` 从 v1.5.1 的报告占位，升级为最薄真实 vertical slice：

- 前端选择已有 active batch / 历史 batch。
- 后端只读取 completed worlds 的 `simulation_dataset.json`。
- 后端生成共享审计产物 `appendix_b.json`。
- 后端调用真实报告模型，生成一份 **B 版无附录** Markdown 报告。
- 前端只展示五态：`idle` / `running` / `completed` / `failed` / `blocked`。
- 前端展示 completed worlds 数量、失败 world 数量、报告文件和错误原因。

**2. 这轮不做什么？**

- 不做完整 fake 动画。
- 不做 A / C 版。
- 不做附录模式选择；本轮固定输出 B 版无附录。
- 不做 `included` / `both`。
- 不做 SKILL 多选；本轮固定使用默认政府报告风格。
- 不做 report job localStorage 恢复。
- 不新增 Pinia report store。
- 不做复杂 job 状态机。
- 不读取 `seed_input_path`。
- 不使用 MCP / 搜索 / 外部事实补全。
- 不让前端接触 API key。
- 不修改 phase、parser、llm_client、simulation_dataset schema。

**3. 为什么这样拆？**

报告模块最早要验收的是"真实报告质量"，不是 fake 状态流。先打通 B 版无附录真实链路，Owner 可以直接看报告内容；v1.5.2b 再补 A/C、附录、SKILL、会话恢复和完整工作台。

**4. 谁调度？谁执行？**

- 调度：Hermes / Owner
- 执行：Codex CLI single_node

### 2. Product Boundary

正式输入只能来自 batch 下 completed worlds 的 `simulation_dataset.json`：

- 第一章概要只能使用 dataset 内字段，例如 `run_info.seed_text`、`source_context.event_summary`、`source_context.event_entities`。
- 禁止 `seed_input_path`、浏览器原始材料上传、外部 URL、MCP 搜索、联网补事实、"LLM 对现实事件的了解"。
- 如果 dataset 信息不足，返回 blocked，不能编造外部事实。
- 产品 `writing_guide.md` 中所有 `seed_input + LLM 现实知识` 规则必须在导入默认 skill 时改写为 dataset-only。

### 3. Request / Response Contract

#### 3.1 请求模型

```ts
interface ReportRequest {

```

本轮固定：

- `versions = ['B']`
- `appendix_mode = 'none'`
- `skill_id = 'default_government'`

type ReportJobStatus = 'idle' | 'running' | 'completed' | 'blocked' | 'failed';

interface ReportJobStatusResponse {

### 4. Thin Backend Scope

新增 `src/adarian/report/` 只保留够用模块：

```text
runner.py             # API 入口；校验 batch/world；串联 appendix -> writer -> quality
appendix_builder.py   # 读取 datasets 并生成 appendix_b.json
writer.py             # 加载 default_government skill，调用 LLM 写 B 版无附录
quality.py            # 最小阻断检查：dataset-only、标题结构、空内容、明显违规词
config.py             # 输出路径、默认参数、模型解析小函数
skills/default_government.md
```

Ponytail 原则：

- 不拆 `aggregation.py`，聚合是 `appendix_builder.py` 的内部步骤。
- 不拆 `model_config.py`，本轮模型解析放 `config.py`。
- 不做 `jobs.py` 持久队列；POST 同步执行或短线程均可，先保证真实产物。
- 不做新依赖。

### 5. Frontend Scope

`06-report.vue` 只做最小可用体验：

- 选择 / 展示当前 batch。
- 展示 completed / failed world 数量。
- 如果部分 failed，显示 `allow_partial` 勾选项："仅基于 completed worlds 生成"。
- 点击"生成 B 版报告"调用 `/api/report`。
- 显示 `running`、`completed`、`blocked`、`failed`。
- completed 后展示 B 版无附录报告下载链接和 `appendix_b.json` 审计产物链接。

不新增 `frontend/src/stores/report.ts`。页面状态先放 `06-report.vue` 内；v1.5.2b 如果需要跨页面恢复，再引入 store。

### 6. Output Path

本轮报告文件放在 batch 目录下：

```text
<batch_dir>/reports/<job_id>/
  appendix_b.json
  B版/
    <safe_event_slug>_舆情风险研判_<YYYYMMDD>_v1_无附录.md
```

规则：

- 未选版本不得创建目录；本轮只允许创建 `B版/`。
- `_无附录.md` 只含四章正文。
- `appendix_b.json` 始终单独输出。
- 本轮不输出 `_含附录.md`。

### 7. World 完整性门

- 无 completed world：返回 `NO_COMPLETED_WORLDS`，blocked。
- 有 completed world 且无 failed：允许生成。
- 有 completed world 且部分 failed：
  - `allow_partial=false`：返回 `PARTIAL_COMPLETED_WORLDS`，blocked。
  - `allow_partial=true`：允许生成，响应里 `partial=true`。
- completed world 缺 `simulation_dataset.json`：返回 `DATASET_MISSING`，blocked。

### 8. Model Config

优先级：

1. `ReportRequest.gateway_id` / `model_id` / 参数。
2. settings 中的 report 默认模型。
3. env：
   - `ADARIAN_REPORT_MODEL`
   - `ADARIAN_REPORT_BASE_URL`
   - `ADARIAN_REPORT_API_KEY`
   - `ADARIAN_REPORT_TEMPERATURE`
   - `ADARIAN_REPORT_MAX_TOKENS`
4. 都缺失则返回 `REPORT_MODEL_NOT_CONFIGURED`。

安全边界：

- 前端不传 API key。
- API key 不返回前端。
- 错误信息只说明缺什么配置，不泄露密钥。

### 9. Error Contract

| code | 场景 |
|------|------|
| `NO_COMPLETED_WORLDS` | batch 无 completed world |
| `PARTIAL_COMPLETED_WORLDS` | 部分 world failed 且用户未允许 partial |
| `DATASET_MISSING` | completed world 缺 simulation_dataset |
| `REPORT_MODEL_NOT_CONFIGURED` | 未配置报告模型 |
| `REPORT_MODEL_UNAVAILABLE` | 模型服务不可用 |
| `APPENDIX_BUILD_FAILED` | appendix_b 构建失败 |
| `REPORT_WRITE_FAILED` | 正文生成失败 |
| `REPORT_QUALITY_BLOCKED` | 质量审核阻断 |
| `REPORT_FILE_FORBIDDEN` | 文件下载越权 |
