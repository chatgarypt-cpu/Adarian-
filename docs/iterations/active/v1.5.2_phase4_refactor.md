# v1.5.2 — 报告重构拆分索引（superseded）

> 本文件原计划为"Skill 驱动的独立报告 Agent"单体迭代。
> 2026-06-27 经产品交付物复核后，原方案已拆分为 1.5.2a / 1.5.2b。

---

## 拆分原因

原 v1.5.2 计划存在三类不准确假设：

1. **错误吸收 ClaudeCode 架构**：产品同学交付的 `adarian-report-agent/` 是 ClaudeCode skill 包，但 Adarian 内部不采用 ClaudeCode skill runtime、不 spawn 子 agent。
2. **产品边界越界**：产品侧报告 agent 当前依赖 `seed_input_path` 和 LLM 现实知识；而 Adarian 产品侧应只消费 `simulation_dataset.json`，最多使用 dataset 内已有 `run_info.seed_text` / `source_context.event_summary`。
3. **产物模型不准确**：A/B/C 版本不是默认全量产出，附录也不是默认双文件输出；版本和附录都应按用户选择生成。

## 保留原则

- 产品交付物中的 `references/*.yaml`、`writing_guide.md`、`quality_checklist.yaml` 是可吸收的**规则资产**。
- 产品交付物中的 ClaudeCode skill 编排、`seed_input_path` 输入、LLM 现实知识补事实，不进入内部架构。
- 报告生成必须建立在 completed worlds 的 `simulation_dataset.json` 上。
- `appendix_b.json` 是内部结构化审计产物，应始终生成并保留；用户阅读报告文件按版本和附录开关按需生成。
