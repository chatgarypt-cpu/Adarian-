### 2. Goal & Boundary

**做什么：**

1. **`serve.py` 冲突修复** — `git mv src/adarian/serve.py src/adarian/_legacy_serve.py`；新建 `serve/__init__.py` 暴露 `run()` 和 `create_app()`；更新 `__main__.py` 导入
2. **SQLite 数据库** — `serve/db.py` 实现 batches（含 idempotency_key UNIQUE）/ worlds / settings 三表；提供 `init_db()` + CRUD 接口
3. **Flask 应用骨架** — app factory + ThreadPoolExecutor(3) + `_SESSIONS` + `_ACTIVE_BATCHES` + `app.run(threaded=True)`
4. **全部业务 API（按前端规格实现）：**
   - `POST /api/seed` — 保存事件材料，返回录入检查结果
   - `GET /api/models` — 模型列表（从 `batch.available_models()` 读取，过滤掉 bge/❌ 等）
   - `POST /api/models/health` — 批量健康检测（调用 `_hello_one` 逻辑）
   - `POST /api/run` — 启动真推演（调 `batch.start_batch`），写入 SQLite，idempotency_key 查重，并发上限 3
   - `GET /api/run/<id>/status` — 从 SQLite worlds 表返回每个 world 状态
   - `POST /api/run/<batch_id>/worlds/<world_id>/retry` — 调 `batch.rerun_world()`，可换模型
   - `POST /api/cancel/<batch_id>` — 遍历 worlds 子进程，SIGTERM → 3s → SIGKILL
   - `POST /api/cancel/<batch_id>/<world_id>` — 单个 world 取消
   - `GET /api/review/<batch_id>` — 聚合跨 world 风险结论
   - `POST /api/report` — 调 Phase 4 报告管线
   - `GET /api/history` — 查 SQLite batches 表，按日期倒序
   - `GET /PUT /api/settings` — 读写 SQLite settings 表
5. **幂等性** — `SELECT batch_id FROM batches WHERE idempotency_key = ?`
6. **并发上限** — `_ACTIVE_BATCHES` 计数 ≥ max_concurrent(3) → 429 + active_batches 列表
7. **进程管理** — `process.py` 封装 subprocess 启动（`preexec_fn=os.setsid`），Popen handle 存到 session
8. **白名单修改 batch.py** — 仅新增 `rerun_world()` 函数 + `WorldState.proc_handle` 字段（AST 检查验证）
9. **前端接入** — 替换 mock 为真实 API 调用；每个页面展示真实 loading/empty/error/populated 状态
10. **SPA catch-all** — `static.py` 注册非 `/api/*` GET → `frontend/dist/index.html`
11. **测试** — pytest 全套 API 测试（每个端点至少 3 断言：状态码、结构、错误路径）
12. **Vite proxy** — `vite.config.ts` 代理 `/api/*` → `http://localhost:9788`

**不做什么：**
- 不改 `phase*/`、`analysis/`、`parser.py`、`llm_client.py`、`schemas/`
- 不改前端 8 页的组件结构（只替换 store 的数据源）
- 不做 E2E 测试（v1.5.0c）

**设计参考：** `docs/adarian_frontend_spec.md` §4 API 类型映射表

old = subprocess.check_output(['git', 'show', 'HEAD:src/adarian/batch.py'], text=True)
