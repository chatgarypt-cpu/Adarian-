## 7. Design Constraints

### 7.1 类型标注不得改变运行行为

`main.py` 的类型标注只用于增强编排层可读性与 contract 约束，不允许引入 runtime validation。

禁止：

```text
改变参数顺序
改变返回值
新增运行时校验
新增依赖框架
改变 Phase 1 → Phase 2 / 3 / 4 数据流
```

---

### 7.2 文件头修复只能修改注释

`src/phase1_entity_extraction.py` 只允许修改文件头 docstring / 注释。

禁止：

```text
修改业务逻辑
修改 prompt
修改 parser
修改 validator
修改 schema
新增 src/phase1/
```

---

### 7.3 contract test 不得调用 LLM

`tests/test_phase1_output_contract.py` 只能验证 schema / object contract 的静态事实。

禁止：

```text
调用 LLM
访问网络
读写 outputs
运行完整 E2E
为了测试修改业务代码
```

### 8.2 Task B：给 main.py 编排函数补最小类型标注

修改文件：

```text
main.py
```

目标函数：

```text
run_phase2(...)
run_phase3(...)
run_phase4(...)
```

最低要求：

```text
extraction_output 标注为 EntityExtractionOutput
phase2_output 标注为 Phase2Output（若当前可安全导入）
tick_logs 标注为 list 或 list[TickLog]（按当前 Python 版本兼容性选择）
output_path 标注为 Optional[Path] 或 Path | None
```

兼容性要求：

```text
不改变函数行为
不改变参数顺序
不改变返回值
不新增 runtime validation
```

如出现循环 import 或类型导入风险，应优先使用：

```python
from __future__ import annotations
```

或：

```python
from typing import TYPE_CHECKING
```

但不得为类型标注重构主链。

## 11. Risk Register

| 风险                     |     等级 | 说明                                     | 处置                                                        |
| ---------------------- | -----: | -------------------------------------- | --------------------------------------------------------- |
| 类型标注触发循环 import        | Medium | main.py 引入类型时可能触发导入链变化                 | 使用 `from __future__ import annotations` 或 `TYPE_CHECKING` |
| contract test 构造对象失败   | Medium | Pydantic 默认值或必填字段可能与预期不一致              | 以当前 schema 事实为准，不修改 schema 迁就测试                           |
| E2E smoke 因远端 LLM 超时失败 | Medium | test1 依赖远端模型，不一定稳定                     | 若失败，区分本地结构错误与远端调用超时                                       |
| 文件头修复误改业务逻辑            |    Low | 注释修复应无功能影响                             | diff 必须确认仅 docstring / comment 变化                         |
| 范围漂移到 R1               |   High | Agent 可能顺手新增 parser/compiler/validator | 明确禁止并在验收中检查                                               |
