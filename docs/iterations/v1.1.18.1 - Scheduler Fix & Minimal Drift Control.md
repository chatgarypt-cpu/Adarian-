# 🔧 详细修改指令（给 Codex）

---

## 任务 1：强制 Scheduler 接管所有 tick

### 问题

当前：

* Tick 1 仍可能全员发言
* 说明 selected_speakers 未真正控制生成循环

---

### 必须修改

在 `run_tick()` 中：

❌ 旧逻辑（示意）

```python
for agent in opinion_spreaders:
    generate_post(agent)
```

---

✅ 新逻辑（必须）

```python
selected_speakers, silent_agents = select_speakers(...)

for agent in selected_speakers:
    generate_post(agent)
```

---

### 强制校验（必须加）

```python
assert len(selected_speakers) < len(opinion_spreaders) or tick == 1_configured_full
```

> 如果 Tick 1 是设计成 100%，必须显式写在 selector 里，而不是隐式回退

---

if tick == 1:
