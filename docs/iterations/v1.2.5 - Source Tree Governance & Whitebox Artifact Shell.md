```text

3. 记录总体 whitebox status。

```

示例结构：

```json
{
  "whitebox_version": "v1.2.5",
  "status": "pass_with_warnings",
  "checks": {
    "report_completeness": {
      "status": "pass",
      "path": "whitebox/report_completeness.json"
    },
    "artifact_check": {
      "status": "pass",
      "path": "whitebox/artifact_check.json"
    }
  },
  "raw_sources": {
    "run_log": "run.log",
    "timing_summary": "timing_summary.json",
    "tick_logs": "tick_logs.json",
    "final_report_md": "final_report.md",
    "final_report_json": "final_report.json",
    "run_meta": "run_meta.json"
  }
}
```

白盒边界：

```text
whitebox 只能观察、检查、汇总、验证；
不能生成；
不能决策；
不能改变模拟行为；
不能替代 RuntimeLogger；
不能成为 runtime authority。
```
