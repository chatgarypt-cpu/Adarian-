## 🎯 本次修复目标

### 问题 1：已故/匿名实体不应发言（严重逻辑错误）
**现象**：
- 胖猫（已故）、当事学生（匿名）在 Tick 0 发言
- 示例：`❌ 胖貓: "我只是一個普通網遊玩家..."`（胖猫已去世）
- 示例：`❌ 當事學生: "我坚决维护事实真相..."`（匿名个体不公开发声）

**解决方案**：
- 新增 `can_speak` 字段，机构默认可发言，个人由 LLM2 判断
- LLM3 校验 `can_speak` 的合理性（检测"已故"、"匿名"等关键词）
- `can_speak=false` 的实体在 Tick 0 不生成发言内容，仅标记为"被讨论实体"

### 问题 2：Tick 0 未提取种子材料中的原始发言
**现象**：
- 系统生成"事后声明"而非"原始发言"
- 示例：
  ```
  种子材料："南通文旅在评论区留下'哪位少爺吸了'一句"
  ❌ 系统生成：南通文旅: "该评论为不当言论，已严肃处理。"
  ✅ 应该是：南通文旅: "哪位少爺吸了"
  ```

**解决方案**：
- LLM 自动识别种子材料中的原始发言（评论、当事人原话等）
- 有原始内容 → 直接引用
- 无原始内容 → 生成对该实体的立场描述

## 🔧 详细修改指令

### 任务 1：修改 schemas.py - 新增字段

**文件**：`src/schemas.py`

**修改**：`Entity` 类增加三个字段：

```python
class Entity(BaseModel):
    name: str
    type: str  # "individual" or "organization"
    role: str
    entity_category: str = "event_entity"

    # v1.1.6 新增
    can_speak: bool = True                    # 是否可以发言
    can_speak_reason: Optional[str] = None    # 不能发言的原因（如果为 False）
    original_statement: Optional[str] = None  # 原始发言（从种子材料提取）
```

### 任务 2：修改 phase1_entity_extraction.py - LLM2 输出格式

**文件**：`src/phase1_entity_extraction.py`

**LLM2 输出格式变更**：event_entity 增加 `can_speak` 和 `original_statement`

```json
{
  "event_entities": [
    {
      "name": "胖貓",
      "type": "individual",
      "role": "事件当事人",
      "entity_category": "event_entity",
      "can_speak": false,
      "can_speak_reason": "已故",
      "original_statement": null
    },
    {
      "name": "兵團禁毒",
      "type": "organization",
      "role": "发布普法视频的官方机构",
      "entity_category": "event_entity",
      "can_speak": true,
      "can_speak_reason": null,
      "original_statement": "我们始终坚决打击毒品犯罪，依法保护每一位公民的合法权益。"
    }
  ]
}
```

**LLM2 Prompt 要点**：
- 自动识别种子材料中的原始发言，填入 `original_statement`
- 个人实体判断 `can_speak`：已故/匿名 → false，普通人 → true
- 机构默认 `can_speak=true`
- 如无原始发言，`original_statement` 设为 null

**LLM3 校验规则**：
- 检测到关键词（已故、去世、死亡、匿名、佚名等），校验 `can_speak=false` 是否设置
- 如检测到关键词但 `can_speak=true`，报错要求修正
- 如未检测到关键词但 `can_speak=false`，要求说明原因

### 任务 3：修改 phase3_tick_simulation.py - Tick 0 发言逻辑

**文件**：`src/phase3_tick_simulation.py`

**Tick 0 发言逻辑**：

```python
# 只让 can_speak=true 的实体发言
for entity in event_entities:
    if entity.can_speak:
        # 发言内容：优先用 original_statement，无则 LLM 生成
        content = entity.original_statement or generate_speech(entity)
        agent_speak(agent_id, content)
    else:
        # can_speak=false：仅标记为被讨论，不生成发言
        mark_as_discussed(entity.name)
```
