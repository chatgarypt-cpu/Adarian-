## 9. Issues

### Blockers
None.

### Known Issues (4 — all deferred to v1.2.12 Phase 4 Report Architecture Hardening)

1. **`_llm_generated_markdown` global state** (`report_agent.py:491`): Works correctly under current call order but fragile. Single-writer, single-reader pattern depends on `generate_report_with_llm()` being called before `save_markdown_report()`.

2. **EmotionTrajectory key_event format gap** (`report_agent.py:594 vs 658`): LLM path writes `Agent #N 发言`, fallback path writes `Agent #N: <comment text>`. Different data quality between paths.

3. **Governance constants not imported by report_agent.py** (`report_prompts.py`): `FIVE_CHAPTER_HEADINGS`, `FORBIDDEN_REALITY_PHRASES`, etc. are imported by tests but semantic content is duplicated in REPORT_SYSTEM_PROMPT string. If prompt string drifts, tests don't catch it.

4. **No runtime LLM output validation** (`report_agent.py:922-951`): `save_markdown_report()` writes LLM output without scanning for forbidden phrases or verifying chapter structure. Enforcement is prompt-only.

### Carry Over (4 — deferred to v1.2.12)

1. v1.1.8 module docstring (`report_agent.py:2-17`)
2. v1.1.8 inline comments (`report_agent.py:502, 566`)
3. `# 风险评估` old terminology in comments (`report_agent.py:605, 648`)
4. `build_entity_distribution()` dead function (`report_agent.py:388-406`)
