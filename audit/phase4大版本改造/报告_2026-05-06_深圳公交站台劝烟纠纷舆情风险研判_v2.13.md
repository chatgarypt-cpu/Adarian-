# 深圳公交站台劝烟纠纷引发执法程序争议舆情风险研判

**作者：**

**日期：2026-05-06**

## 一、舆情概要

2026年4月下旬，深圳一名女子在公交站台劝阻吸烟反被警方认定"涉嫌侮辱"拟行政拘留，而吸烟男子未被追责，事件经中国新闻周刊等媒体报道后引发强烈社会反响。涉事民警现场表示"公交站不算室内禁烟区"，与《深圳经济特区控制吸烟条例》第八条明确将公交站台列为法定禁烟场所的规定形成直接冲突。女子反映在被传唤期间遭强制脱衣搜身、限制如厕等人身权益侵害，而吸烟者未受任何处罚，"守法者受罚、违法者逍遥"的结果激起公众对执法程序公正性的深度疑虑。

推演显示，该事件规模评分为0.70，属于区域性热点事件；争议性评分为0.85，呈高度对立态势。舆情推演共设置7个事件实体、8个意见传播群体，6轮模拟周期内累计生成47条发言消息。情绪均值从首轮的5.07降至第六轮的4.74，反映舆论整体从观望偏中立向批评方向持续移动；极化指数从0.37攀升至0.39，已进入高危极化区间，批评阵营与理解阵营之间的立场鸿沟在模拟周期内未见弥合迹象。

## 三、风险研判

当前舆情推演风险等级为低风险，情绪均值4.74处于中立偏批评区间，但极化指数已达0.39，进入高危极化区间，两项指标之间的背离构成了风险研判的核心张力——低风险评级反映的是事件烈度尚未达到危机级别，而高危极化反映的是社会意见的深度撕裂，二者共同指向一个判断：事件烈度可控，但舆论结构脆弱，任何新的刺激性信息都可能迅速改变态势。

具体而言，存在以下三个层面的结构性风险。

一是缓冲群体流失风险。中立观望派立场从8.60大幅降至5.00，降幅3.60，是全周期最剧烈的单一群体立场迁移。该群体占比仅5%，但其人口学特征——大学教师为代表的知识阶层——决定了其舆论影响力远超人数占比。该群体从"让子弹飞一会儿"的高信任位退至"等待完整证据链"的审慎观望位，意味着舆论场中愿意为官方调查"留出时间窗口"的理性声音已大幅减弱。其当前5.00的立场处于可进可退的敏感位置：一次有说服力的官方回应可能将其拉回信任区间，而一次被认为"避重就轻"的回应则可能将其彻底推入质疑区间，届时极化指数大概率突破0.40。

二是传播放大风险。年轻围观派立场下降2.45，从4.45降至2.00，进入强烈批评区间。该群体以18至24岁的大学生和职场新人为核心，是社交媒体的重度用户和信息传播的关键节点，观点扩散能力在八类群体中最为突出。其发言内容经历了从"我真的会谢""无语子"等情绪化表达到"法律面前应该人人平等"等价值判断的显著升级——传播内容一旦从情绪输出转向价值判断，其说服力和渗透性将成倍增长，推动事件从区域舆情向全国性议题转化的风险不可忽视。

三是专业背书风险。执法质疑派立场强度高达9.0、易感性低至0.10，在全部8个群体中"硬度"最高。其发言始终围绕"程序正义""选择性执法""双重标准"等核心法律概念展开，为该事件的所有批评声音提供了一套高度自洽的专业分析框架。该群体立场虽仅从1.70小幅升至2.50，但变化方向是更加接近"以法言法"的中立表达——这一"去情绪化"的趋势反而增强了其批评话语的公信力。律师群体作为事件实体在首轮只发言一次，但其"三个核心法律问题"的分析框架被执法质疑派、中立观望派、程序理性派在后续轮次中反复引用，形成了专业话语对大众舆论的持续赋能效应。该群体立场近乎免疫于外部信息（易感性0.10），意味着舆论场上永远存在一个无法被任何回应所消解的批评内核。

从风险演化预判来看：短期内，舆情将维持"质疑为主、两极固化"的格局，深圳市公安局"正在核查"的程序性表态已不足以改变舆论走向。中期来看，调查结果的公布是最大的变量——如果结果能够逐一回应执法标准对等性、搜身程序合法性、吸烟者处置依据三个核心问题，中立观望派的立场可能出现回升，极化指数有望回落至0.35以下；反之，如果调查结果被舆论认为"避重就轻"，中立观望派将大概率向质疑区间迁移，极化指数可能突破0.40。长期来看，该事件折射的控烟执法"立法先进、执行打折"的困境具有全国性——深圳作为控烟立法的先行城市，其执法实践对全国具有标杆效应，若该事件暴露的执法标准不一致问题未能得到系统性回应，可能影响其他城市控烟执法的公众配合度和社会认同度。

## 四、对策建议

针对当前舆情态势及上述风险研判，提出以下对策建议。

一是尽快公布调查结果，直接回应核心质疑。深圳市公安局在完成核查后，应在公布调查结果时逐一回应以下公众核心关切：公交站台是否属于《深圳经济特区控制吸烟条例》第八条所规定的法定禁烟场所，以及涉事民警"公交站不算室内禁烟区"的当场表态是否有法律依据；对吸烟者未予追责的具体原因和法定程序；对劝阻者拟行政拘留的裁量标准及其与治安管理处罚法的衔接；传唤期间的搜身程序是否符合《公安机关办理行政案件程序规定》中"尊重人格尊严"的原则要求。鉴于中立观望派立场已从8.60降至5.00、对"正在核查"类程序性表态已产生信任疲劳，调查结果的公布应当同步配发执法依据说明，以透明度对冲质疑，争取将这一关键群体的立场重新拉回信任区间。

二是统一执法标准，消除选择性质疑。建议深圳市公安局联合市卫健委，以该事件为契机对全市控烟执法标准进行系统梳理和统一规范。重点解决两个问题：其一，明确公交站台、高铁站、地铁口等场所的控烟执法主体和程序，消除权责分离造成的执法真空——当前铁路和交通部门仅有劝阻权、处罚需卫健部门执行但后者缺乏常驻力量的现状，直接导致投诉处理周期过长和执法标准不统一；其二，建立"双方行为分别审查"的执法原则，确保在劝阻者与吸烟者并存的复杂执法场景中，双方的违法行为均被依法独立评价，避免出现"只罚一方"的执法结果。这一举措直接回应执法质疑派的持续性关注焦点，从制度层面消除"选择性执法"的土壤。

三是建立舆情回应长效机制。建议由深圳市公安局牵头，联动市卫健委、市委宣传部，建立涉及公共利益的执法舆情三方联动研判和协同回应机制。鉴于该事件中深圳市公安局首轮声明后全程沉默、信息真空被批评声音持续填充的教训，长效机制应设置"执法说理"专门环节——回应内容不仅要有调查结论，更要就公众关注的核心疑点逐一提供法律和政策层面的解释，实现从"告知结果"到"解释过程"的回应模式升级。特别建议将回应节奏与舆论演化节奏对齐：在调查进行中定期发布阶段性进展，避免长时间信息真空导致群体立场固化。

四是强化控烟执法人员法规培训。鉴于涉事民警"公交站不算室内禁烟区"的表述暴露出基层执法人员对控烟条例认知的不足，建议组织全市一线执法人员开展《深圳经济特区控制吸烟条例》专项培训，统一对法定禁烟场所范围的认识，并将控烟条例与治安管理处罚法的衔接关系纳入培训内容。培训应重点覆盖"劝阻者过激行为"与"吸烟者违法行为"并存的复合场景的处置规范，使一线执法人员在面对类似情形时，能够依法对等审查、分别处理，从源头减少因执法人员个体认知差异导致的执法标准争议。这一举措与执法质疑派提出的"程序正义不仅是走流程，更要求同等情况同等对待"的核心关切直接对应。

五是推动控烟执法技术赋能。建议探索运用AI图像识别技术自动检测公共场所吸烟行为，降低取证难度和执法成本，减少因"现场无证据"而导致的执法不均问题。深圳作为科技创新城市，在执法技术化方面具备先发优势，技术赋能的控烟执法不仅有助于提升执法效率和公信力，更可作为"科技向善"的正面案例对冲该事件对城市形象带来的负面影响。

### （二）数据说明

本报告所有参数指标的计算方法及核心参数定义说明如下。

**1. 核心参数定义**

（1）环境参数

事件规模（event_scale）：事件影响范围，取值范围0.0-1.0，0.0表示个人事件，1.0表示全社会事件。生成依据为由Analyzer在Phase 1判断。在Phase 1中的影响：决定Agent总人数（<0.3为3-5人，0.3-0.7为5-7人，≥0.7为7-10人）和I分布（<0.3时I偏中立3-6，≥0.7时I高度分化3-10）。本事件event_scale=0.70，对应Agent总数7-10人，I值呈高度分化分布。

事件争议性（event_controversy）：事件立场对立程度，取值范围0.0-1.0，0.0表示事实清晰，1.0表示高度对立。生成依据为由Analyzer在Phase 1判断。在Phase 1中的影响：控制P（立场方向）分布（<0.3时反对40%/支持60%，0.3-0.7时反对55%/支持45%，>0.7时反对70%/支持30%）。本事件event_controversy=0.85，对应反对群体占比70%、支持群体占比30%，舆论高度对立。

（2）实体参数

立场分（stance_score）：量化主体对事件态度的指标，取值范围1.0-10.0，语义如下：1.0-3.0表示强烈批评，4.0-6.0表示中立观望，7.0-10.0表示强烈支持。生成依据为由Generator在Phase 1生成archetype时判断，无量化公式，纯主观评分。

易感性（susceptibility）：Agent被他人发言影响的程度，取值范围0.0-1.0，数值越高表示越容易被说服。生成依据为由Generator在Phase 1生成archetype时判断。在模拟中通过公式susceptibility_modulation = 1 + 0.5 × (susceptibility - 0.5)调制stance变化幅度：susceptibility=1.0时变化幅度×1.25，susceptibility=0.5时变化幅度不变，susceptibility=0.0时变化幅度×0.75。

立场强度（I）：Opinion Spreader的立场坚定程度，取值范围1.0-10.0，语义如下：I=1-3表示极易动摇，I=4-6表示中等坚定，I=7-10表示极度坚定。生成依据为由Generator在Phase 1生成。在Phase 3中的作用：I越高越不容易被说服改变立场；I决定P：I≥6时P=+1，I≤5时P=-1。

立场方向（P）：Opinion Spreader的立场方向，取值+1或-1，+1表示支持/维护，-1表示反对/批评。生成依据为由Generator在Phase 1生成，由I决定。在Phase 3中与C（一致性）共同决定立场计算：P=+1时stance_score=I，P=-1时stance_score=11-I。

一致性（C）：立场一致性指标，由系统固定推导，公式为C = P × (I/10)。C > 0表示支持方向的一致性强度，C < 0表示反对方向的一致性强度，|C|越大立场越坚定。

发言权限（can_speak）：事件实体是否可以发言，布尔值，true表示可以发言，false表示不可发言。生成依据为由Generator在Phase 1判断。在模拟中控制Tick 0发言：为false时不生成发言，标记为"被讨论"。

**2. 计算方法说明**

（1）情绪与极化指标计算

情绪均值（Mean）计算方式：对指定模拟轮次内所有Agent的立场分求算术平均，公式为 Mean(t) = (1/N) × Σ stance_i(t)，其中N为Agent总数，stance_i(t)为第i个Agent在模拟轮次t的立场分。Mean(t)为t时刻的情绪均值。

标准差（Standard Deviation）计算方式：衡量群体立场分歧的统计量，公式为 Std(t) = sqrt((1/N) × Σ(stance_i(t) - Mean(t))^2)，其中Mean(t)为t时刻的情绪均值。Std(t)越大表示群体立场越分散。

极化指数（Polarization Index）定义与计算方法：极化指数为标准差与均值之比，用于量化群体立场分歧程度，公式为 Polarization(t) = Std(t) / Mean(t)，其中Std(t)为t时刻的标准差，Mean(t)为t时刻的情绪均值。极化指数越高表示群体意见越分散。

（2）立场演化指标计算

立场分变化量（Δstance）计算方式：群体立场变化量为该群体在第六轮模拟与首轮模拟的立场分之差，公式为 Δstance = stance(5) - stance(0)。正值表示立场上升，负值表示立场下降。

**3. 判别标准说明**

（1）拐点识别标准

拐点识别标准：当某一模拟轮次的极化指数较前一轮次变化超过0.05，或任意群体立场偏移超过1.5时，判定为拐点事件。

判断流程：
1. 分别检验极化指数变化条件（>0.05）和群体立场偏移条件（>1.5）
2. 任一条件满足即可判定为拐点事件
3. 记录满足条件的拐点，并说明该拐点的触发条件

参考实现：
```python
from dataclasses import dataclass
from typing import List, Optional

@dataclass
class InflectionPoint:
    tick: int
    trigger_type: str
    group_name: Optional[str]
    polarization_change: Optional[float]
    stance_shift: Optional[float]
    description: str

def detect_inflection_points(tick_logs: List[dict]) -> List[InflectionPoint]:
    inflection_points = []
    for i in range(1, len(tick_logs)):
        prev_polarization = tick_logs[i-1]["global_metrics"]["polarization_index"]
        curr_polarization = tick_logs[i]["global_metrics"]["polarization_index"]
        pol_change = curr_polarization - prev_polarization
        if abs(pol_change) > 0.05:
            desc = f"极化指数变化 {pol_change:+.2f}，{'极化加剧' if pol_change > 0 else '极化缓和'}"
            inflection_points.append(InflectionPoint(i, "polarization", None, pol_change, None, desc))
        for entry in tick_logs[i]["entries"]:
            stance_shift = abs(entry["stance_delta"])
            if stance_shift > 1.5:
                group = entry["group_name"]
                direction = "上升" if entry["stance_delta"] > 0 else "下降"
                desc = f"{group}立场{direction} {entry['stance_delta']:.2f}"
                inflection_points.append(InflectionPoint(i, "stance_shift", group, None, entry["stance_delta"], desc))
    return inflection_points

def generate_inflection_analysis(tick_logs: List[dict]) -> str:
    points = detect_inflection_points(tick_logs)
    if not points:
        return "本次模拟周期内未出现满足拐点识别标准的显著拐点事件。"
    lines = [f"Tick {p.tick} 出现拐点：{p.description}。"]
    for p in points:
        if p.trigger_type == "polarization":
            lines.append(f"触发条件：极化指数变化 {p.polarization_change:+.2f}（>{'0.05' if abs(p.polarization_change) > 0.05 else '未超阈值'}）。")
        else:
            lines.append(f"触发条件：{p.group_name}立场偏移 {p.stance_shift:.2f}（>1.5阈值）。")
    return " ".join(lines)
```
