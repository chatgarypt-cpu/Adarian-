# 政府治理视角舆情风险分层与等级映射清单 v0.2

> 适用对象：Adarian 多智能体异步舆情预判系统 Phase 4 报告生成环节  
> 目标读者：政府舆情治理人员、公安/监管/公共管理部门、学校与公共机构管理方  
> 交付定位：产品侧业务分类说明，用于技术侧后续转译为 code-owned deterministic rules；本文不提供代码、JSON schema、阈值公式或数据库字段。

> **v0.2 修订说明**：本版在 v0.1 基础上，对照产品任务卡验收标准进行复核与小幅修订。总体判断为“基本符合任务卡要求，可进入技术侧规则转译讨论”；本版重点修正三处：  
> 1. 将“公共服务回应压力风险”从“公共安全与民生类”调整至“治理执行压力类”，以更贴合任务卡对该类型的归属建议；  
> 2. 扩展“信息安全与意识形态类”中“意识形态与价值观对冲风险”的边界，将“涉外叙事、国家形象污名化、境外信息操纵”等内参式高敏线索纳入，但保持克制表达，避免泛政治化；  
> 3. 增补“任务卡符合性核验表”和“类型合并/增补说明”，便于技术侧判断 v0.2 与任务卡要求的一致性。

---

## 1. 总体说明

### 1.1 本清单解决的问题

当前系统的风险等级判断已经能够区分 LOW / MEDIUM / HIGH / CRITICAL，但“主要风险类型”容易泛化为“负向叙事风险”。本清单将风险类型从单纯文本关键词匹配，调整为“治理主体—公共利益—传播演化—处置压力”的业务语义分类，使技术侧可将其转译为确定性规则。

### 1.2 方法依据

本清单综合三类依据：

1. **项目内部任务依据**：用户提供的《政府治理视角舆情风险分层与等级映射——综合简报》，其中明确了政府治理视角、4 档风险等级、4 个推荐一级域、21 个候选二级风险类型及每类 12 字段要求。
2. **风险治理理论依据**：IRGC 风险治理框架强调风险识别、评估、管理与沟通需纳入社会语境、复杂性、不确定性和模糊性；OECD 关于关键风险治理的文件强调政府在跨部门协调、预防、准备、响应和恢复中的责任。
3. **传播与危机沟通依据**：社会风险放大框架说明风险事件会经由媒体、社交网络、群体认知和制度信任被放大；WHO 与 CDC 的风险/危机沟通框架强调“及时、准确、可信、透明、共情、促进行动”的公共沟通原则；UNESCO 平台治理文件强调虚假信息、意识形态极化、仇恨与暴力煽动对公共信息生态的影响。

### 1.3 使用边界

- 本清单用于**模拟舆情报告中的风险类型解释**，不是现实执法、司法或行政责任认定。
- Adarian 的极化指数、立场均值、趋势等均为**模拟产物**，报告中应使用“模拟显示”“模拟观察到”“可能提示”等表达，不应写成现实舆情实测结论。
- 风险类型不是处置建议，也不是法律判断；它只回答“该事件在政府治理视角下更像哪类风险”。
- 同一事件可命中多个风险类型，但报告主类型建议控制在 1—3 个，避免类型堆砌。

### 1.4 四档风险等级的业务含义

| 等级 | 中文标签 | 业务含义 | 判断核心 |
|---|---|---|---|
| LOW | 低风险 | 局部争议，尚未形成明显治理压力或传播外溢 | 零散信号、局部关注、低强度质疑 |
| MEDIUM | 中风险 | 已形成一定关注或治理压力，负向叙事开始聚合 | 共同框架出现、责任追问上升、信息缺口扩大 |
| HIGH | 高风险 | 多信号叠加，治理主体、监管主体或公共机构开始承压 | 多主体卷入、跨平台扩散、强问责或极化 |
| CRITICAL | 重大风险 | 多层级外溢，可能形成系统性问责、公共秩序压力或重大治理风险 | 线下行动、重大伤亡、敏感群体、跨区域/跨部门外溢 |

### 1.6 v0.2 的类型合并与增补说明

| 处理方式 | 涉及类型 | 理由 |
|---|---|---|
| 合并 | “校园治理风险”与“未成年人保护风险”合并为“校园与未成年人保护风险” | 两者在任务卡语境中高度重合，均指向学校/机构保护义务、未成年人权益和家长群体动员 |
| 合并 | “民生保障风险”与“弱势群体保护风险”合并为“民生保障与弱势群体保护风险” | 二者均围绕基本生活、权益救济和兜底保障，合并后更便于规则转译 |
| 合并 | “次生传播扩散风险”与“议题外溢风险”合并为“次生传播与议题外溢风险” | 二者均描述传播链条扩张和原议题被重新框定，分开易造成重复命中 |
| 合并 | “平台治理关注风险”与“消费争议外溢风险”合并为“平台治理与消费争议外溢风险” | 企业消费纠纷只有外溢至平台规则、消费权益或监管响应时才进入政府治理视角 |
| 增补 | “AI/深度伪造滥用风险”“数据与网络安全关注风险” | 产品任务卡虽未列为原始候选，但该类风险已成为公共信息秩序和平台治理中的高敏场景，建议在 MVP 中保留 |
| 增补/扩展 | “意识形态、价值观与涉外叙事风险” | 用于覆盖历史叙事、价值观对冲、国家形象污名化、境外信息操纵等高敏表达，但需通过“不应触发情况”防止泛化 |


## 2. 一级风险域说明

本清单建议采用 **5 个一级风险域、20 个二级风险类型**。相较产品任务卡原有 4 个一级域，新增“信息安全与意识形态类”，用于承接内参汇编中“网络与信息安全”“政治安全与意识形态”“文化安全”等高敏议题。该域不宜拆得过多，否则会使 MVP 规则体系过重；但完全不设则会遗漏 AI 深度伪造、数据安全、意识形态/价值观对冲等技术侧明确需要覆盖的类型。

| 一级风险域 | 定义 | 边界 |
|---|---|---|
| 治理信任类 | 公众将事件解释为监管、执法、处置、政策或问责问题，进而影响对公共机构的信任 | 不包括纯企业品牌声誉、普通商业口碑 |
| 公共安全与民生类 | 事件涉及生命健康、公共安全、校园、未成年人、弱势群体、基本民生或公共服务保障 | 不包括单纯消费偏好、娱乐争议 |
| 传播演化类 | 舆论在模拟传播中出现负向叙事聚合、极化、外溢、谣言与事实混淆 | 不直接判断责任，只描述传播结构变化 |
| 信息安全与意识形态类 | 涉及 AI/深度伪造、数据网络安全、价值观对冲、文化安全、国家形象等高敏信息秩序议题 | 不把一般观点分歧扩大为意识形态风险 |
| 治理执行压力类 | 事件给基层、跨部门、平台治理、公共服务响应等执行环节带来压力 | 不包括责任主体清晰的普通企业内部纠纷 |

## 4. 各风险类型详细说明

### 4.1 监管信任风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理信任类 |
| 适用场景 | 食品安全、产品质量、市场监管、安全生产、行业监管等事件 |
| 触发线索 | 监管缺位、监管滞后、抽检/许可/备案被质疑、群众要求说明监管责任边界 |
| LOW 表现 | 零散质疑监管是否及时介入，尚未形成集中追问 |
| MEDIUM 表现 | 讨论焦点从事件本身转向监管是否到位，出现较稳定的追责叙事 |
| HIGH 表现 | 监管部门回应、执法依据或既往监管记录被持续质疑，跨平台形成问责压力 |
| CRITICAL 表现 | 叠加伤亡、未成年人、重大民生或跨区域问题，多部门被卷入系统性问责 |
| 不应触发情况 | 单纯企业营销、售后或品牌口碑争议，未涉及公共安全、市场秩序或监管责任 |
| 报告表达口径 | 公众关注点已由单一事件延伸至监管响应、处置透明度与责任边界，需关注由个案争议向治理信任议题转化的可能。 |

**正例**：产品质量问题被曝光后，舆论集中质疑监管部门抽检、许可或日常检查是否到位。  
**反例**：某品牌广告文案引发反感，但不涉及产品安全、行业监管或公共利益损害。

### 4.2 执法公信风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理信任类 |
| 适用场景 | 公安、交警、城管、市场监管、行政处罚、现场处置等执法类事件 |
| 触发线索 | 选择性执法、程序不透明、执法尺度争议、暴力/过度执法、证据链不清 |
| LOW 表现 | 对个别执法动作或态度存在争议 |
| MEDIUM 表现 | 公众开始追问程序是否规范、依据是否充分 |
| HIGH 表现 | 执法主体公正性被集中质疑，出现官民对立、弱者叙事或选择性执法叙事 |
| CRITICAL 表现 | 线下秩序、群体对立、重大伤害或上级调查问责叠加，公信力议题外溢 |
| 不应触发情况 | 普通企业客服、校园内部管理、平台处罚争议，未涉及行政执法或公权力行使 |
| 报告表达口径 | 相关讨论已指向执法过程的规范性、公正性和解释充分性，需防范个案处置争议放大为执法公信议题。 |

**正例**：现场执法视频传播后，网民集中质疑是否存在程序违法或区别对待。  
**反例**：电商平台封禁商家账号引发争议，但主体为平台内部规则执行。

### 4.3 处置透明度风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理信任类 |
| 适用场景 | 突发事件、公共服务事故、校园/医院/交通/安全事件、官方通报争议 |
| 触发线索 | 信息发布迟缓、关键事实缺失、口径前后不一、回避核心问题、通报被认为模糊 |
| LOW 表现 | 公众要求补充事实或时间线 |
| MEDIUM 表现 | 对官方回应是否充分、是否避重就轻产生集中讨论 |
| HIGH 表现 | 多轮回应仍未消除疑点，舆论将信息缺口解释为隐瞒或推责 |
| CRITICAL 表现 | 重大伤亡、敏感群体、跨部门责任与信息不一致叠加，形成强问责和信任危机 |
| 不应触发情况 | 事实清楚且主体已及时说明，仅存在少量情绪性不满 |
| 报告表达口径 | 事件回应中的事实链条、责任边界和处置进展仍存在信息缺口，公众对回应充分性和透明度的关注正在上升。 |

**正例**：学校发布简短说明后未回应学生受伤原因，引发家长持续追问。  
**反例**：媒体报道已完整披露处理流程，评论区仅对个别措辞不满。

### 4.4 舆论问责升级风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理信任类 |
| 适用场景 | 涉及公共机构、干部作风、监管失责、失职渎职猜测的事件 |
| 触发线索 | 要求调查、处分、追责、上级介入、实名举报、旧案翻出、责任链延伸 |
| LOW 表现 | 个别声音提出追责要求 |
| MEDIUM 表现 | 追责对象由直接责任人扩展至单位或主管部门 |
| HIGH 表现 | 舆论要求上级部门介入，既往同类问题被翻出，形成责任链追问 |
| CRITICAL 表现 | 多层级主体被卷入，可能引发系统性问责、组织声誉和治理合法性压力 |
| 不应触发情况 | 仅要求企业道歉、赔偿或解释，未涉及公共权力责任链 |
| 报告表达口径 | 舆论焦点正在由事实争议转向责任追究与上级介入，需关注问责对象扩大化带来的治理承压。 |

**正例**：事故处置后，公众从“谁造成事故”进一步追问“主管部门为何长期未发现”。  
**反例**：消费者要求商家退款赔偿，但未指向监管部门或公共机构责任。

### 4.5 政策解释压力风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理信任类 |
| 适用场景 | 政策发布、调整、执行、收费、补贴、教育医疗住房等公共政策议题 |
| 触发线索 | 政策被简化解读、利益受损群体集中表达、执行口径不一、误读扩散 |
| LOW 表现 | 少量用户对政策含义或适用对象表示不理解 |
| MEDIUM 表现 | 误读开始围绕利益影响聚合，需要权威解释 |
| HIGH 表现 | 不同地区/部门解释不一致，舆论将政策理解为不公平或不合理 |
| CRITICAL 表现 | 政策误读与群体利益、民生压力、线下诉求叠加，形成较大治理压力 |

| 触发线索 | 部门回应不一致、职责交叉、互相推诿、属地与主管部门边界不清 |
| LOW 表现 | 公众不清楚由谁负责 |
| MEDIUM 表现 | 开始质疑部门之间是否推诿或回应不一致 |
| HIGH 表现 | 多部门口径冲突，责任边界成为争议核心 |
| CRITICAL 表现 | 上级统筹、联合调查或跨区域处置失灵叠加，形成重大协同压力 |
| 不应触发情况 | 责任主体单一且边界清晰，无多部门介入必要 |
| 报告表达口径 | 事件处置可能由单点回应转向跨部门协同和责任边界压力，需关注不同主体口径不一致带来的治理信任损耗。 |

**正例**：食品配送安全事件中，市场监管、教育、平台等多方回应不一致。  
**反例**：企业内部劳动争议责任主体明确，不涉及多部门协同。

### 4.20 平台治理与消费争议外溢风险

| 字段 | 内容 |
|---|---|
| 一级风险域 | 治理执行压力类 |
| 适用场景 | 电商、外卖、直播、社交平台、算法推荐、平台交易、消费维权事件 |
| 触发线索 | 平台审核失灵、算法放大、投诉无门、售后争议群聚、平台规则不透明 |
| LOW 表现 | 个别消费者投诉平台处理不佳 |
| MEDIUM 表现 | 同类投诉聚集，平台规则或审核责任被质疑 |
| HIGH 表现 | 争议外溢到监管、消费者权益保护或平台治理责任 |
| CRITICAL 表现 | 大规模消费者维权、未成年人/弱势群体受损、监管介入或线下维权叠加 |
| 不应触发情况 | 单个商家与消费者轻微纠纷，平台未被指向治理责任 |
| 报告表达口径 | 消费争议正在外溢为平台治理、消费者权益保护和监管响应议题，需关注个案维权聚集后的公共治理压力。 |

**正例**：直播带货售后争议大量聚集，消费者质疑平台审核和监管是否到位。  
**反例**：某用户与小店协商退货，未形成群体投诉或平台责任争议。

## 5. 正例 / 反例汇总

| 风险类型 | 正例功能 | 反例功能 |
|---|---|---|
| 治理信任类 | 识别公共机构、监管、执法、政策解释、问责链条相关争议 | 拦截纯企业品牌、普通售后、娱乐化争议 |
| 公共安全与民生类 | 识别生命健康、安全感、未成年人、弱势群体、基本民生与公共服务保障 | 拦截口味、审美、价格、个人体验等非公共安全议题 |
| 传播演化类 | 识别叙事聚合、极化、跨平台外溢、谣言混淆等传播结构变化 | 拦截低热度单点抱怨、专业争论、普通观点差异 |
| 信息安全与意识形态类 | 识别深度伪造、数据安全、意识形态/价值观对冲、涉外叙事和国家形象污名化等高敏信息秩序问题 | 拦截明确标注的二创、普通审美争议、理性学术讨论、非误导性技术故障 |
| 治理执行压力类 | 识别基层承压、跨部门协同、平台治理和消费争议外溢 | 拦截责任清晰的单一主体纠纷 |

## 6. 产品侧补充建议

### 6.1 技术转译时建议关注的业务信号

技术侧后续做 deterministic rules 时，不建议只抓关键词，而应组合判断以下业务信号：

| 信号组 | 说明 |
|---|---|
| 主体信号 | 是否涉及政府部门、监管部门、公安政法、学校、医院、公共服务机构、平台企业、基层组织 |
| 对象信号 | 是否涉及未成年人、老年人、低收入群体、患者、学生、消费者、居民等特定群体 |
| 行为信号 | 是否出现监管、执法、回应、通报、处罚、检测、召回、救助、投诉、维权、举报、调查等动作 |
| 责任信号 | 是否出现缺位、推诿、迟缓、不透明、不一致、选择性、走过场、隐瞒等归因 |
| 传播信号 | 是否出现跨平台扩散、旧案翻出、二创剪辑、大 V 介入、评论阵营化、谣言多版本并存 |
| 强度信号 | 是否叠加伤亡、线下聚集、未成年人、跨区域、多部门、公共服务中断、官方回应失效等升级条件 |

### 6.2 主风险与副风险建议

- **主风险类型**：优先选择最能解释治理压力来源的类型。例如，食品安全事件中如果公众主要追问监管部门，则“监管信任风险”优先于“食品与产品安全治理风险”。
- **副风险类型**：用于补充传播形态或执行压力。例如，主风险为“处置透明度风险”，副风险可为“谣言与事实混淆风险”或“跨部门协同与责任边界风险”。
- **避免兜底滥用**：“负向叙事聚合风险”只能在叙事框架已经形成时触发，不能作为所有负面评论的默认标签。

### 6.3 等级跃迁的判断原则

| 跃迁 | 典型条件 |
|---|---|
| LOW → MEDIUM | 从零散情绪变成共同议题；从个体抱怨变成群体追问；从事实争议变成责任归因 |
| MEDIUM → HIGH | 多主体卷入、跨平台扩散、权威回应被质疑、旧案/同类问题被系统关联 |
| HIGH → CRITICAL | 重大伤亡、未成年人/弱势群体、线下行动、公共秩序压力、跨区域/跨部门外溢、系统性问责叠加 |

### 6.4 报告写作口径约束

建议报告中使用：

- “模拟观察显示……”
- “相关讨论呈现出……倾向”
- “需关注……进一步扩散的可能”
- “当前风险主要体现为……，尚不宜直接判断为……”
- “该风险并非对现实责任的定性，而是对模拟传播中治理压力来源的归纳”

避免使用：

- “已经造成严重后果”（除非现实材料明确）
- “必然引发群体性事件”
- “监管失职”“违法违规”（除非官方已有结论）
- “品牌危机”“客户流失”“营销翻车”等企业 PR 话术
