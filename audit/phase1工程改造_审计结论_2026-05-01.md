## 下游字段依赖初判

### Phase 2

入口：`build_topology_from_extraction(extraction_output)`

真实依赖：

- `extraction_output.event_entities`
- `extraction_output.opinion_spreaders`

`event_entities` 依赖字段：

- `name`：生成 Core 节点 `group_name` / `related_entity`，并建立 entity map。

`opinion_spreaders` 依赖字段：

- `group_name`
- `related_event_entity`
- `I` / `P`，通过 `stance_score` 派生属性进入 GraphNode。
- `susceptibility`
- `persona_name`
- `age_range`
- `occupation`
- `personality`
- `motivation`
- `typical_phrases`

Phase 2 当前不直接使用：

- `event_summary`
- `event_scale`
- `event_controversy`
- `event_type`
- `relations`
- `event_entities[].can_speak`
- `event_entities[].original_statement`
- `opinion_spreaders[].estimated_percentage`
- `opinion_spreaders[].communication_style`
- `opinion_spreaders[].description`

注意：`related_event_entity` 必须能匹配某个 `event_entities[].name`，否则 Periphery -> Core 的关注边会缺失，且 schema 层当前已有校验。

### Phase 3

入口：`SimulationEngine(extraction_output, phase2_output, seed_text)`

真实依赖：

- `event_summary`
- `event_entities`
- `opinion_spreaders`

`event_entities` 依赖字段：

- `name`
- `type`
- `role`
- `can_speak`
- `original_statement`
- `can_speak_reason`

Phase 3 在 Tick 0 中使用 `can_speak` 决定事件实体是否发言；使用 `original_statement` 优先复用种子材料中的原始发言；使用 `can_speak_reason` 作为白盒观测字段来源。

`opinion_spreaders` 依赖字段：

- `group_name`：建立 spreader map。
- 其他传播者 persona 和 stance 字段主要由 Phase 2 转入 GraphNode，Phase 3 通过 `phase2_output.nodes` 驱动后续 tick。
- `confirmation_bias_level`、`stance_score`、`susceptibility` 等模拟用字段在 Phase 3 中主要来自 GraphNode，而 GraphNode 又由 Phase 2 基于 Phase 1 的 `I / P / susceptibility / persona_*` 构建。因此这些字段属于间接强依赖，不应被 Compiler 改断。

### Phase 4

入口：`generate_report_with_llm(...)` 与 `save_markdown_report(...)`

真实依赖：

- `event_summary`
- `event_type`
- `event_scale`
- `event_controversy`
- `event_entities`
- `opinion_spreaders`

`event_entities` 依赖字段：

- `name`
- `type`
- `role`
- `can_speak`
- `original_statement`
- `can_speak_reason`

`opinion_spreaders` 依赖字段：

- `group_name`
- `related_event_entity`
- `estimated_percentage`
- `I` / `P`，通过 `stance_score` 派生属性用于展示。
- `confirmation_bias_level` 派生属性用于展示。

Phase 4 当前不明显依赖：

- `relations`
- `opinion_spreaders[].persona_name`
- `age_range`
- `occupation`
- `personality`
- `motivation`
- `typical_phrases`

但这些 persona 字段会被 Phase 2 透传到 GraphNode，间接影响 Phase 3 的发言生成上下文，因此不能删除或改名。它们对 Phase 4 不一定是直接依赖，但对主链模拟语义是间接强依赖。

### main.py

主链传递方式：

- `run_phase1()` 返回 `extraction_output` 对象。
- `run_phase2(extraction_output)` 直接消费 Phase 1 对象。
- `run_phase3(extraction_output, phase2_output, seed_text)` 继续消费 Phase 1 对象。
- `run_phase4(extraction_output, phase2_output, tick_logs, x_t_sequence)` 继续消费 Phase 1 对象。

主链不是通过重新读取 `entities_and_relations.json` 来串联 Phase 2/3/4，而是通过内存中的 `EntityExtractionOutput` 传递。JSON 文件是运行产物与审计证据，不是主链唯一数据通道。

## 字段分级建议

### required_fields

短期不可删除，否则会直接破坏当前主链或核心报告：

- `event_summary`
- `event_scale`
- `event_controversy`
- `event_type`
- `event_entities`
- `event_entities[].name`
- `event_entities[].type`
- `event_entities[].role`
- `event_entities[].can_speak`
- `event_entities[].original_statement`
- `opinion_spreaders`
- `opinion_spreaders[].group_name`
- `opinion_spreaders[].related_event_entity`
- `opinion_spreaders[].I`
- `opinion_spreaders[].P`
- `opinion_spreaders[].susceptibility`
- `opinion_spreaders[].persona_name`
- `opinion_spreaders[].age_range`
- `opinion_spreaders[].occupation`
- `opinion_spreaders[].personality`
- `opinion_spreaders[].motivation`
- `opinion_spreaders[].typical_phrases`

### optional_fields

当前存在，但部分下游非强依赖或主要用于展示/审计：

- `relations`
- `event_entities[].can_speak_reason`
- `event_entities[].entity_category`
- `opinion_spreaders[].description`
- `opinion_spreaders[].estimated_percentage`
- `opinion_spreaders[].communication_style`
- `opinion_spreaders[].entity_category`

说明：

- `can_speak_reason` 当前对白盒观测和报告说明有价值，虽然字段 Optional，但建议保留并补强。
- `estimated_percentage` 当前主要被 Phase 4 展示使用，不直接驱动 Phase 2/3 主模拟，但仍属于报告契约字段，不能在 R1 前删除。
- `entity_category` 当前有默认值，代码大多通过模型对象使用，但它是输出语义边界的一部分，建议 R0 中列为“可默认、不可反向改义”字段。

### legacy_fields

当前没有作为 JSON 落盘字段，但存在兼容属性或历史语义：

- `stance_score`：由 `I / P` 派生，用于兼容 Phase 2/3/4。
- `confirmation_bias_level`：由 `I` 派生，用于兼容展示。
- `C`：由 `P * (I / 10)` 派生，属于 IPC 语义。
- `group_distribution_strategy`：Phase 3 使用 `getattr(..., "normal")` 兼容读取，当前不属于 `EntityExtractionOutput` 固定输出字段。

### candidate_intermediate_fields

适合后续迁移到 intermediate object 或 Compiler 内部结构：

- Parser 原始 payload。
- Analyzer 输出：`event_summary` / `event_scale` / `event_controversy` / `event_type`。
- 传播者规划字段：`I` / `P` / `susceptibility` / `estimated_percentage`。
- persona 表达字段：`persona_name` / `age_range` / `occupation` / `personality` / `motivation` / `typical_phrases` / `communication_style`。
- 派生字段：`C` / `stance_score` / `confirmation_bias_level`。
- 修复/校验证据：validator errors、repair attempts、diff report。

### forbidden_to_change_fields

R1 前短期禁止变更：

- 顶层字段名与基本类型：`event_summary`, `event_scale`, `event_controversy`, `event_type`, `event_entities`, `opinion_spreaders`, `relations`。
- `event_entities[].name` 与 `opinion_spreaders[].related_event_entity` 的引用关系。
- `I` / `P` 的取值语义和派生 `stance_score` 的兼容行为。
- `can_speak` 对 Tick 0 speaker behavior 的控制语义。
- `original_statement` 优先作为 Tick 0 原始发言的语义。
- `EntityExtractionOutput` 作为 Phase 1 对下游的 canonical object。

## 主要风险

1. 文档漂移风险高：路线图引用了当前不存在的 `src/phase1/orchestrator.py` 与 `src/phase1/rules_engine.py`。
2. 文件头漂移风险高：`src/phase1_entity_extraction.py` 自称已迁移到 `src/phase1/`，但目标目录不存在。
3. 契约误判风险中等：`C`、`stance_score`、`confirmation_bias_level` 是派生属性，不应被要求 LLM 直接输出。
4. 间接依赖漏判风险中等：persona 字段对 Phase 4 不一定直接使用，但经 Phase 2 进入 GraphNode 后影响 Phase 3 发言生成。
5. 回滚风险已降低：已有 checkpoint `f9fae60` 与 hygiene commit `b13dd57`，运行产物已退踪；但正式 R0 前仍应保持工作树干净。
6. R1 事故风险中等：如果不先完成 R0，Parser / Compiler 很容易改变字段名、字段来源或派生语义，破坏 Phase 2/3/4。
7. 测试边界风险中等：当前 tests 主要覆盖 JSON parser，缺少针对 Phase 1 output contract 的契约测试。
