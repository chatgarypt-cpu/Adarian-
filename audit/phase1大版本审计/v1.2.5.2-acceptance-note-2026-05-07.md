## 6. Findings

### Finding A1: Per-Agent Stance Values in Markdown Diverge from tick_logs

- **finding_id**: ACCEPT-F1
- **severity**: LOW
- **location**: Phase 4 Markdown 报告 "各群体立场偏移矩阵" 表 vs `tick_logs.json` per-agent `current_stance`
- **description**: LLM 在生成 Markdown 时独立综合 per-agent stance 值，产出与 tick_logs 精确值不同的数字（如 跟风吐槽网友 MD=6.9→4.5, tick_logs=8.04→4.5）。差异源于 LLM 进行了独立的起止点选择和数值四舍五入，而非从结构化数据直填。
- **recommendation**: v1.2.6 将 per-agent stance 数据也以结构化方式传入 REPORT_SYSTEM_PROMPT，让 LLM 引用而非重算
- **requires_codex**: no (非阻塞)
- **suggested_action**: 记录为 known issue，在 v1.2.6 prompt registry 改进时一并处理

### Finding A2: Inflection Point Count Mismatch — Code vs LLM Threshold

- **finding_id**: ACCEPT-F2
- **severity**: LOW
- **location**: Phase 4 `identify_inflection_points()` (code: pol_delta > 0.1) vs REPORT_SYSTEM_PROMPT (LLM: pol_delta > 0.05 或 stance偏移 > 1.5)
- **description**: 同一 run 中 `final_report.json` 的 `inflection_points` 为空数组（代码阈值 0.1），但 Markdown 宣称有 1 个拐点（LLM 阈值 0.05 + stance偏移 1.5）。消费者读 JSON 和 Markdown 会得到矛盾的拐点结论。
- **recommendation**: v1.2.6 将 `identify_inflection_points()` 的输出传入 prompt，或统一两边的阈值
- **requires_codex**: no (非阻塞)
- **suggested_action**: 记录为 known issue，v1.2.6 中统一阈值或 pass-through

### Finding A3: event_scale/event_controversy Not in final_report.json

- **finding_id**: ACCEPT-F3
- **severity**: LOW (informational)
- **location**: `final_report.json` (Phase4Output schema) 不含 event_scale/event_controversy
- **description**: Markdown 报告的 "事件规模 0.80" 和 "事件争议性 0.60" 需追溯到 `entities_and_relations.json` 才能验证。`Phase4Output` schema 不包含这两个字段，但 Markdown 中出现了——LLM 从 `build_full_report_context()` 的文本上下文中获取。
- **recommendation**: 可选——如果下游消费者需要，在 Phase4Output 中增加 event_scale/event_controversy 字段
- **requires_codex**: no
- **suggested_action**: 低优先级，不阻塞

### Finding A4: Process Issue — team_mode_used=false

- **finding_id**: ACCEPT-PROC1
- **severity**: PROCESS (不影响内容)
- **location**: v1.2.5.2 审计报告 line "team_mode_used: false"
- **description**: DS Master 跳过了 6 reviewer 并行交叉验证的 DS Team 标准流程，自行完成了全量源码读取和分类。内容质量未受损（所有 12 个源文件均已读取），但流程缺少多 reviewer 的制衡步骤。
