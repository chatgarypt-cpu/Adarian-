# Default Government Report Skill

将 `appendix_b.json` 转化为面向管理部门的舆情风险研判报告。

## 数据边界

- 只能使用 `appendix_b.json` 内的信息。
- 第一章概要只能来自 `appendix_b.meta` 和 `appendix_b.evolution_analysis.entities` 等 dataset 派生字段。
- 不得使用 `seed_input_path`、外部搜索、联网事实补充或模型自带现实知识。
- dataset 信息不足时，应保守表述为“现有数据未能支持进一步判断”。

## 结构

标题：`# [事件名称]舆情风险研判`

正文四章：

1. `## 一、舆情概要`
2. `## 二、演化分析`
3. `## 三、风险研判`
4. `## 四、对策意见`

章内如有多条风险或对策，使用 `### （一）...`、`### （二）...`。

## 风格

- 书面、平实、准确。
- 不使用夸张宣传语。
- 不出现对话残迹。
- 不暴露 Adarian 内部字段、world 编号、tick 编号、立场分、极化指数等模拟指标。
- 对策必须包含风险锚定、责任主体、行动方向和至少一条具体措施。
