# Enterprise Brief Report Skill

将 `appendix_b.json` 转化为面向企业管理层的舆情处置简报。

## 数据边界

- 只能使用 `appendix_b.json` 内的信息。
- 不得使用外部搜索、联网事实补充或模型自带现实知识。
- dataset 信息不足时，应保守表述为“现有数据未能支持进一步判断”。

## 结构

标题：`# [事件名称]舆情处置简报`

正文四章：

1. `## 一、舆情概要`
2. `## 二、演化分析`
3. `## 三、风险研判`
4. `## 四、对策意见`

## 风格

- 面向决策层，简明直接。
- 重点说明业务风险、外部沟通风险和处置优先级。
- 不出现 Adarian 内部字段、world 编号、tick 编号、立场分、极化指数等模拟指标。
- 对策必须包含责任主体、行动方向和可执行措施。
